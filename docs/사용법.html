화면 주석 QA — 사용법

고칠 곳을 화면에서 두 번 클릭해 남기면, 개발자가 바로 찾을 수 있는 정보 (CSS 경로·위치·크기·글꼴·색)가 자동으로 붙습니다. 스크린샷을 따로 붙이지 않아도 됩니다.

이것만 기억하세요. ①exe → ②[QA 시작] → ③두 번 클릭하고 메모 → ④Ctrl+Enter → ⑤[클립보드 복사]

1. 시작하기

  1. 바탕화면 화면주석-QA.exe 를 두 번 클릭합니다. 파란 경고창이 나오면 [추가 정보] → [실행]. 서명이 없는 프로그램이라 그렇습니다.
  2. 주소를 확인하고 QA 시작 — 전용 브라우저가 열립니다. 처음 한 번만 로그인하면 다음부터 유지됩니다.
  3. 화면 우측 아래 둥근 버튼을 누르거나 Esc 를 눌러 주석 모드를 켭니다.
이 버튼을 찾으세요.
화면 우측 아래의 검은 둥근 버튼입니다. 주석을 남기면 개수가 배지로 표시됩니다.
버튼을 찾지 않아도 Esc 로 켜고 끌 수 있습니다.

2. 화면에 주석 남기기

① 마우스를 올리면 테두리와 요소 이름이 보입니다.
② 두 번 클릭하면 메모창이 열립니다. 적고 Ctrl+Enter 로 확정합니다. 입력칸은 넉넉하게 커져 있습니다.
이렇게 하면이렇게 됩니다
두 번 클릭그 요소 하나에 메모 — 대부분 이걸로 끝납니다
글자를 드래그한 뒤 두 번 클릭그 문구가 그대로 첨부됩니다 — 오타·표현 지적에 가장 좋습니다
빈 곳부터 사각형으로 드래그여러 요소를 한 덩이로 — 정렬·간격 차이가 숫자로 결과에 적힙니다
툴바의 레이아웃 모드요소를 직접 옮겨 원하는 배치를 보여 줍니다

단축키

Esc 주석 모드 켜기·끄기 · Ctrl+Enter 메모 확정 · Delete 선택한 주석 삭제

한 번 클릭은 아무 일도 하지 않습니다. 실수로 메모창이 뜨는 것을 막기 위해서입니다.
주석 모드에서는 페이지의 원래 클릭(메뉴·링크·버튼·썸네일)이 동작하지 않습니다. 화면을 옮기려면 Esc 로 끄고 이동한 뒤 다시 Esc.

3. 팝업(모달)에 주석 달기

팝업 안의 요소에도 그대로 주석을 달 수 있습니다. 순서만 지켜 주세요.

  1. Esc 로 주석 모드를 끄고 팝업을 엽니다. 모드가 켜져 있으면 팝업을 여는 버튼도 눌리지 않습니다.
  2. 팝업이 열린 상태에서 둥근 버튼으로 주석 모드를 켭니다. 1초쯤 뒤에 눌립니다 — 도구가 팝업 위로 올라가는 시간입니다.
  3. 팝업 안을 두 번 클릭해 메모를 남깁니다.
팝업이 열려 있는 동안 Esc 는 주석 모드를 켜지 않습니다. 그 Esc 는 팝업을 닫는 데 쓰라는 뜻입니다. 그때는 둥근 버튼으로 켜세요.
반대로 주석 모드가 켜져 있으면 Esc 로 팝업이 닫히지 않습니다 — 지적하려던 팝업이 사라지지 않게 도구가 막습니다.

화면을 덮는 팝업, 아주 높은 층에 올린 팝업, 브라우저 기본 팝업(<dialog>) 모두 됩니다. 팝업 안이 또 다른 iframe 인 경우에만 안쪽을 고를 수 없습니다.

4. 관리자 화면(좌측 메뉴가 있는 구조)

내용이 iframe 안에 있는 구조에서는 도구가 내용 영역을 담당합니다.

기본 (자동)“툴바를 최상위 화면에 고정”을 켜면
내용 영역 주석됩니다안 됩니다
좌측 메뉴·상단바 주석안 됩니다됩니다
모드를 끄지 않고 메뉴 이동됩니다안 됩니다
둘 중 하나만 됩니다. 브라우저는 서로 다른 화면(iframe) 안쪽을 한 번에 다룰 수 없습니다. 그래서 필요할 때 프로그램 창의 체크박스로 바꿔 쓰세요. 바꿔도 남긴 주석은 그대로 있습니다.
지금 어느 쪽인지는 툴바 위에 적혀 있습니다. 주석 모드를 켜면 툴바 바로 위에 자동 · iframe 문서 또는 최상위 고정 · 최상위 문서 와 함께 지금 무엇을 고를 수 있는지가 뜹니다.
“더블클릭했는데 안 잡힌다” 싶으면 먼저 이 표시를 보세요. 고장이 아니라 모드 때문인 경우가 대부분입니다. 뒤에 붙은 v1.0 (001) 은 도구의 판 번호입니다 — 문의할 때 이 번호를 함께 알려 주시면 어느 판에서 난 일인지 바로 압니다.

5. 프로그램 창

화면 왼쪽 화살표를 누르면 그 화면의 주석이 펼쳐집니다.
테스트할 주소 · QA 시작 브라우저를 엽니다. 이미 열려 있으면 그 창을 그 주소로 보냅니다.
오른쪽 위 배지주입됨 = 도구가 떠 있음 · 주입 대기 = 준비 중(2~3초). 레이아웃을 바꿨으면 레이아웃 변경 N 도 함께 보입니다 (브라우저 화면에서도 툴바 위에 같은 표시가 뜹니다).
목록화면별로 쌓입니다. 주석 줄을 두 번 클릭하면 보강 창이 열립니다(6절).
주소를 클릭하면 그 화면으로 이동합니다.
Ctrl+↑/↓ 로 순서를 옮깁니다 — 주석 줄은 그 화면 안에서, 화면 줄은 화면끼리. 결과 문서도 그 순서로 나옵니다.
우클릭 하면 같은 것을 메뉴로 고를 수 있습니다.
클립보드 복사전체를 글로 만들어 담습니다. 프로그램을 닫아도 유지됩니다.
추출 (저장 후 삭제)파일로 저장하고 목록을 비웁니다.
보내기 전 확인복사·추출을 누르면 총평을 물어본 뒤 결과 문서 전문을 보여 줍니다. 거기서 직접 고칠 수도 있습니다 — 오타를 다듬거나 사내에서 빼야 할 내용을 지우고 보낼 때 씁니다.
고친 내용은 이번 복사·저장에만 반영되고 목록은 그대로 남습니다.
이슈에 올리기확인 창에서 누르면 이슈 주소를 묻고, 그 화면을 열어 댓글칸에 내용을 채워 줍니다.
★[등록] 은 직접 누르셔야 합니다 — 도구가 대신 등록하지 않습니다. 확인하고 고친 뒤 누르세요.
비밀번호·토큰을 넣지 않습니다. 이 브라우저에 로그인해 두면 그 상태를 그대로 씁니다. 댓글칸을 못 찾으면 내용을 클립보드에 담아 두니 Ctrl+V 로 붙여넣으세요.
비우기 (보관)목록을 비웁니다. 원본은 결과 폴더의 archive 에 남습니다.
되돌리기실수로 지웠을 때 되살립니다. 목록과 결과 문서는 되살아나지만, 브라우저 화면의 핀은 되살아나지 않습니다.
지난 기록추출·비우기로 정리한 기록을 다시 불러옵니다. archive 에서 파일을 고르면 현재 목록에 합쳐집니다.
같은 주소가 두 줄로 보일 때가 있습니다. 창 크기나 확대 비율이 다르면 다른 화면으로 셉니다 — “1920에서는 정상인데 1366에서 깨진다”가 그대로 남습니다.

6. 보강 창 — 기대·우선순위·연결

화면에서 적은 메모가 “현재”입니다. 받는 사람이 되묻지 않게 “기대”와 우선순위를 여기서 붙입니다.

목록에서 주석 줄을 두 번 클릭하면 열립니다.
우선순위높음 / 보통 / 낮음. 결과 문서의 목차가 이 순서로 정렬됩니다.
기대“이렇게 되어야 합니다”. 메모(현재)와 나눠 적으면 개발자가 되묻지 않습니다.
보충 메모앞뒤 조작·재현 조건처럼 나중에 덧붙일 설명.
관련 주석원인이 다른 화면에 있을 때 연결합니다. 예: “A 화면의 이 값이 틀린 것은 B 화면의 저장 때문”.
연결하면 양쪽 결과에 서로를 가리키는 줄이 함께 들어갑니다.

목록에는 [높음] · →기대 · ✎(보충) · ↔숫자(연결)로 표시됩니다.

7. 결과에 담기는 것

문서 맨 앞총평 + 항목 목차(한 줄씩, 우선순위순) — 이슈 댓글에 그대로 붙이면 됩니다.
화면마다주소 · 제목 · 해상도와 확대비율 · 시각 · 색 기준(다크/라이트) · 그 화면의 콘솔 오류·실패한 요청(요청은 실패 사유까지 함께) · 짧은 조회 응답(“목록이 비었다”가 서버 때문인지 화면 때문인지 가릅니다)
주석마다요소 이름 · 메모 · 기대 · 우선순위 · 시각 · CSS 경로 · 요소 속성 · 위치/크기 · 글꼴·색 · 보충 · 관련

8. 막힐 때

메뉴·링크가 안 눌린다 주석 모드가 켜져 있습니다. Esc 로 끄고 이동하세요.
한 번 클릭했는데 아무 일이 없다 두 번 클릭해야 메모창이 열립니다(2절).
팝업 안을 못 고른다 팝업을 먼저 열고 주석 모드를 켜세요. 켠 뒤 1초쯤 기다립니다(3절).
Esc 를 눌렀는데 아무 일이 없다 팝업이 열려 있으면 일부러 막습니다. 둥근 버튼으로 모드를 켜세요.
우측 아래 버튼이 안 보인다 2~3초 기다린 뒤 배지가 주입됨인지 확인 → 아니면 QA 시작을 한 번 더. 브라우저 설정 페이지·PDF 화면에서는 뜨지 않습니다.
목록에 안 쌓인다 도구가 프로그램이 띄운 창에 있어야 합니다. 평소 쓰는 브라우저 창에서는 수집되지 않습니다.
실수로 지웠다되돌리기 를 누르세요.
추출한 걸 다시 봐야 한다지난 기록 → archive 에서 고르기.
그 외 오류 결과 폴더의 crash.log 와 프로그램 창의 진행 상황 내용을 그대로 전달해 주세요.

9. 알아두면 좋은 것

  • 스크린샷을 붙이지 않아도 됩니다. 그림 대신 CSS 경로·좌표·글꼴·색·정렬 숫자가 들어갑니다 — 개발자와 AI 가 그 값으로 코드를 찾습니다.
  • 브라우저에 설치되는 것이 없습니다 — 북마크·확장·인증서 전부 없음.
  • 전용 브라우저 창이라 평소 쓰는 브라우저의 로그인·북마크와 섞이지 않습니다.
  • 주석은 메모를 다는 즉시 프로그램으로 넘어갑니다. 따로 [보내기] 를 누를 필요가 없습니다.
  • 프로그램을 닫았다 켜도 지난 목록이 복원됩니다.

QA 전용 도구입니다. 이 문서의 그림은 실제 화면을 캡처한 것입니다. 주석 기능은 agentation 을 쓰며 문구만 한글로 바꿨습니다(PolyForm Shield 1.0.0).
