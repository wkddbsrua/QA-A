화면 주석 QA — 사용법

고칠 곳을 화면에서 두 번 클릭해 남기면, 개발자가 바로 찾을 수 있는 정보 (CSS 경로·위치·크기·글꼴·색)가 자동으로 붙습니다. 스크린샷을 따로 붙이지 않아도 됩니다 — 그래도 필요하면 메모에 그림을 붙일 수 있습니다(2절).

이것만 기억하세요. ①exe → ②[QA 시작] → ③두 번 클릭하고 메모 → ④Ctrl+Enter → ⑤[클립보드 복사]

1. 시작하기

  1. 바탕화면 화면주석-QA.exe 를 두 번 클릭합니다. 파란 경고창이 나오면 [추가 정보] → [실행]. 서명이 없는 프로그램이라 그렇습니다.
  2. 주소를 확인하고 QA 시작 — 전용 브라우저가 열립니다. 처음 한 번만 로그인하면 다음부터 유지됩니다.
  3. 화면 우측 아래 둥근 버튼을 누르거나 Esc 를 눌러 주석 모드를 켭니다.
이 버튼을 찾으세요.
화면 우측 아래의 검은 둥근 버튼입니다. 주석을 남기면 개수가 배지로 표시됩니다.
버튼을 찾지 않아도 Esc 로 켜고 끌 수 있습니다.

2. 화면에 주석 남기기

① 마우스를 올리면 테두리와 요소 이름이 보입니다.
② 두 번 클릭하면 메모창이 열립니다. 적고 Ctrl+Enter 로 확정합니다. 입력칸은 넉넉하게 커져 있습니다.
이렇게 하면이렇게 됩니다
두 번 클릭그 요소 하나에 메모 — 대부분 이걸로 끝납니다
글자를 드래그한 뒤 두 번 클릭그 문구가 그대로 첨부됩니다 — 오타·표현 지적에 가장 좋습니다
빈 곳부터 사각형으로 드래그여러 요소를 한 덩이로 — 정렬·간격 차이가 숫자로 결과에 적힙니다
툴바의 레이아웃 모드요소를 직접 옮겨 원하는 배치를 보여 줍니다 — 프로그램 목록에도 그대로 보입니다(4절)
메모 적는 중 Ctrl+V(캡처 후) 또는 파일을 끌어다 놓기 그림이 메모 밑에 작게 붙습니다. 확정하면 그 그림도 함께 저장됩니다
메모창의 ✂ 화면 잘라 붙이기 화면이 살짝 어두워지면 보여줄 부분을 드래그하세요. 그 부분이 그림으로 메모 밑에 붙습니다 (Esc 취소). Win+Shift+S 를 대신하는 것이고 캡처 도구가 따로 필요 없습니다

Esc 주석 모드 켜기·끄기 · Ctrl+Enter 메모 확정 · Delete 선택한 주석 삭제

한 번 클릭은 아무 일도 하지 않습니다. 실수로 메모창이 뜨는 것을 막기 위해서입니다.
주석 모드에서는 페이지의 원래 클릭(메뉴·링크·버튼·썸네일)이 동작하지 않습니다. 화면을 옮기려면 Esc 로 끄고 이동한 뒤 다시 Esc.
그림은 QA 가 고른 부분만 붙습니다 — 메모창의 ✂ 화면 잘라 붙이기로 영역을 드래그하거나, 캡처 도구(Win+Shift+S)로 자른 뒤 붙여넣습니다. 도구가 주석마다 화면을 대신 찍지 않습니다. 무엇을 얼마나 보여줄지는 QA 가 직접 고릅니다.
그림은 클립보드 복사에는 따라가지 않습니다. 추출·이슈에 올리기·Jira 로 보내기로만 전달됩니다(5절) — 대부분은 그림 없이 텍스트만으로 충분합니다.
이와 별개로 보낼 때 화면마다 한 장씩 전체 캡처가 자동으로 붙습니다(번호 핀 포함, 4절 캡처 갱신).

3. 팝업·관리자 화면

팝업 안의 요소에도 그대로 주석을 달 수 있습니다. 순서만 지켜 주세요.

  1. Esc 로 주석 모드를 끄고 팝업을 엽니다. 모드가 켜져 있으면 팝업을 여는 버튼도 눌리지 않습니다.
  2. 팝업이 열린 상태에서 둥근 버튼으로 주석 모드를 켭니다. 1초쯤 뒤에 눌립니다 — 도구가 팝업 위로 올라가는 시간입니다.
  3. 팝업 안을 두 번 클릭해 메모를 남깁니다.
팝업이 열려 있는 동안 Esc 는 주석 모드를 켜지 않습니다. 그 Esc 는 팝업을 닫는 데 쓰라는 뜻입니다. 그때는 둥근 버튼으로 켜세요.
반대로 주석 모드가 켜져 있으면 Esc 로 팝업이 닫히지 않습니다 — 지적하려던 팝업이 사라지지 않게 도구가 막습니다.

화면을 덮는 팝업, 아주 높은 층에 올린 팝업, 브라우저 기본 팝업(<dialog>) 모두 됩니다. 팝업 안이 또 다른 iframe 인 경우에만 안쪽을 고를 수 없습니다.

내용이 iframe 안에 있는 관리자 화면(좌측 메뉴가 있는 구조)에서는 기본으로 도구가 내용 영역만 담당합니다. 프로그램 창의 “상단바·좌측 메뉴도 함께 고르기”를 켜면 상단바·좌측 메뉴와 내용 영역을 모두 고를 수 있습니다(눈에는 툴바가 하나만 보이고, 모드는 두 쪽에 같이 켜집니다).

지금 어느 쪽인지는 툴바 위에 적혀 있습니다. 주석 모드를 켜면 툴바 바로 위에 자동 또는 둘 다 고르기 와 함께 지금 무엇을 고를 수 있는지가 뜹니다.
“더블클릭했는데 안 잡힌다” 싶으면 먼저 이 표시를 보세요. 고장이 아니라 모드 때문인 경우가 대부분입니다. 뒤에 붙은 v1.0 (001) 은 도구의 판 번호입니다 — 문의할 때 이 번호를 함께 알려 주시면 어느 판에서 난 일인지 바로 압니다.

4. 프로그램 창

화면 왼쪽 화살표를 누르면 그 화면의 주석이 펼쳐집니다.

목록

테스트할 주소 · QA 시작 브라우저를 엽니다. 이미 열려 있으면 그 창을 그 주소로 보냅니다.
오른쪽 위 배지주입됨 = 도구가 떠 있음 · 주입 대기 = 준비 중(2~3초). 레이아웃을 바꿨으면 레이아웃 변경 N 도 함께 보입니다 (브라우저 화면에서도 툴바 위에 같은 표시가 뜹니다).
목록화면별로 쌓입니다. 주석 줄을 두 번 클릭하면 보강 창이 열립니다(아래).
주소를 클릭하면 그 화면으로 이동합니다.
줄을 마우스로 끌어 순서를 바꾸거나, Ctrl+↑/↓ 로 옮깁니다 — 주석 줄은 그 화면 안에서, 화면 줄은 화면끼리. 결과 문서도 그 순서로 나옵니다.
우클릭 하면 같은 것을 메뉴로 고를 수 있습니다.
보강 창에서 하위로 묶은 주석은 그 밑에 1.1 처럼 들여써 보이고, 화살표로 접었다 펼 수 있습니다. 레이아웃 모드에서 옮긴 것은 ⇄ 줄로 함께 보입니다.
클립보드 복사전체를 글로 만들어 담습니다. 프로그램을 닫아도 유지됩니다. 그림은 여기에 따라가지 않습니다 - 파일명만 적힙니다.
추출 (저장 후 삭제)파일로 저장하고 목록을 비웁니다. 첨부 그림이 있으면 문서(.md)와 그림을 하나로 묶은 .zip 으로 저장합니다.
보내기 전 확인복사·추출을 누르면 총평을 물어본 뒤 결과 문서 전문을 보여 줍니다. 거기서 직접 고칠 수도 있습니다 — 오타를 다듬거나 사내에서 빼야 할 내용을 지우고 보낼 때 씁니다.
고친 내용은 이번 복사·저장에만 반영되고 목록은 그대로 남습니다.
이슈에 올리기확인 창에서 누르면 이슈 주소를 묻고, 그 화면을 열어 댓글칸에 내용을 채워 줍니다. 첨부 그림이 있으면 “그림 N장도 함께 올리기” 체크로 같이 보낼지 고를 수 있습니다.
★[등록] 은 직접 누르셔야 합니다 — 도구가 대신 등록하지 않습니다. 확인하고 고친 뒤 누르세요.
비밀번호·토큰을 넣지 않습니다. 이 브라우저에 로그인해 두면 그 상태를 그대로 씁니다. 댓글칸을 못 찾으면 내용을 클립보드에 담아 두니 Ctrl+V 로 붙여넣으세요. 그림을 자동으로 못 넣었으면 첨부 폴더를 열어 드립니다.
캡처 갱신지금 열려 있는 화면을 화면마다 한 장씩 위에서 아래까지 찍고, 그 화면의 항목 번호(1·1.1)를 빨간 핀으로 겹칩니다. 결과 문서의 번호와 같습니다. 보내기 전 확인 창에 들어갈 때도 자동으로 한 번 찍습니다.
주석마다 찍는 것이 아니라 화면당 한 장입니다. 열려 있지 않은 화면은 "캡처 없음" 으로 뜹니다 — 목록의 주소를 눌러 그 화면을 열고 다시 캡처 갱신. 목록의 화면 제목 뒤 📷시각이 찍힌 표시입니다.
비우기 (보관)목록을 비웁니다 = 이번 회차를 닫고 새 회차를 엽니다. 닫힌 회차는 지난 기록에서 읽기 전용으로 볼 수 있습니다(그림·캡처 포함).
되돌리기실수로 지웠을 때 되살립니다. 목록과 결과 문서는 되살아나지만, 브라우저 화면의 핀은 되살아나지 않습니다.
지난 기록추출·비우기로 닫힌 회차 목록입니다. 보기로 그 회차 문서를 읽고, 다시 보내기로 복사·저장·이슈·Jira 로 다시 보낼 수 있습니다.
지난 회차는 고칠 수 없고 현재 목록에 합쳐지지도 않습니다 — 예전에 "지난 기록을 불러오면 값이 바뀐다" 가 생긴 원인이 합치기였습니다. 예전 판의 .jsonl 파일은 옛 jsonl 가져오기로 지난 회차에 넣습니다.
Jira 설정 (오른쪽 위)내 Jira 계정으로 바로 올리고 싶을 때 이메일과 API 토큰을 넣습니다. 토큰 발급 페이지 열기를 누르면 Atlassian 토큰 페이지가 열립니다 → API 토큰 만들기 → 복사 → 붙여넣기. 한 번만 넣으면 됩니다. 토큰은 이 PC 의 내 계정에서만 풀리게 암호화되어 저장됩니다. 연결 확인으로 맞는지 봅니다. 토큰이 없어도 됩니다 — 그때는 이슈에 올리기(등록은 직접)를 쓰세요.
같은 주소가 두 줄로 보일 때가 있습니다. 창 크기나 확대 비율이 다르면 다른 화면으로 셉니다 — “1920에서는 정상인데 1366에서 깨진다”가 그대로 남습니다.

보강 창 — 기대·우선순위·하위 주석·첨부 그림

화면에서 적은 메모가 “현재”입니다. 받는 사람이 되묻지 않게 “기대”와 우선순위를 여기서 붙입니다.

목록에서 주석 줄을 두 번 클릭하면 열립니다.
우선순위높음 / 보통 / 낮음. 결과 문서의 목차가 이 순서로 정렬됩니다.
기대“이렇게 되어야 합니다”. 메모(현재)와 나눠 적으면 개발자가 되묻지 않습니다.
보충 메모앞뒤 조작·재현 조건처럼 나중에 덧붙일 설명.
하위 주석원인이 다른 화면에 있거나, 한 건으로 묶어 보일 때 씁니다. 예: “A 화면의 이 값이 틀린 것은 B 화면의 저장 때문” → B 를 A 의 하위로 묶습니다.
여러 개를 한 번에 고를 수 있습니다(Ctrl 또는 Shift 로 다중 선택). 결과 문서와 목록에서 1.1 · 1.2 처럼 그 주석 밑에 들어가고, 목록에서 접었다 펼 수 있습니다. 하위 주석은 상위를 하나만 가질 수 있습니다.
첨부 (그림 · 동영상)화면의 메모창에 붙인 그림이 먼저 와 있습니다.
화면에서 잘라 붙이기 — 브라우저에 그 화면이 열려 있으면 화면이 어두워지고, 그 주석의 요소가 미리 표시됩니다. Enter 면 그 영역 그대로, 드래그하면 새 영역, Esc 취소.
파일 추가 — 그림뿐 아니라 동영상(Win+Alt+R 로 녹화한 .mp4)도 붙습니다. 100MB 가 넘으면 한 번 묻습니다. 클립보드에서 붙이기·열기·빼기도 있습니다.
클립보드 복사에는 따라가지 않고, 추출(zip)·이슈에 올리기·Jira 로 보내기로만 전달됩니다.
변경 이력이 주석의 메모가 언제 어떻게 바뀌었는지(추가·수정·삭제·되돌림)를 이번 회차 안에서 보여 줍니다. "값이 바뀐 것 같다" 싶을 때 여기서 확인합니다.

목록에는 [높음] · →기대 · ✎(보충) · ⤷숫자(하위) · 📎숫자(첨부)로 표시됩니다. ★재지적 이 붙으면 지난 회차에도 같은 자리를 지적했다는 뜻입니다.

5. 보내기

클립보드 복사 메일·메신저·이슈에 그대로 붙여넣습니다. 그림은 따라가지 않습니다(파일명만 적힘).
추출 파일로 저장합니다. 첨부 그림이 있으면 문서와 그림을 하나로 묶은 .zip 파일 하나로 나옵니다 — 이 파일 하나만 넘기면 그림까지 전달됩니다.
이슈에 올리기 이슈 화면을 열고 댓글칸을 채웁니다. 그림이 있으면 함께 넣을지 체크로 고릅니다. [등록] 은 항상 직접 누릅니다. 토큰이 없는 사람용 길입니다.
Jira 로 보내기 (토큰) 내 계정으로 새 이슈를 만들거나 기존 이슈에 댓글을 답니다. 첨부 그림·동영상·화면 캡처가 실제 첨부로 올라가고 본문 안에 그림이 미리보기로 들어갑니다. 먼저 Jira 설정에 이메일과 API 토큰을 넣어야 합니다.
프로젝트와 이슈 유형은 목록에서 고릅니다 — 내 계정이 이슈를 만들 수 있는 프로젝트만 나옵니다 (기본 유형은 QA). 기존 이슈에 댓글로 달 때는 이슈 키(예: SC-123)만 넣습니다.
이 길은 [보내기]를 누르면 도구가 등록합니다. 파일이 일부 안 올라가면 어떤 파일이 왜 빠졌는지 결과창에 나옵니다 — 그때는 "기존 이슈에 댓글" 로 그 이슈 키에 다시 보내세요(이슈가 중복으로 생기지 않습니다).

추출한 파일이 .zip 이다 그림이나 화면 캡처가 있는 회차입니다. 열어 보면 문서(.md)와 첨부·캡처 폴더가 들어 있습니다.
