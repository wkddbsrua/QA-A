화면 주석 QA — 사용법

고칠 곳을 화면에서 클릭해 남기면, 개발자가 바로 찾을 수 있는 정보(요소 위치·크기·글꼴·색)가 자동으로 붙습니다. 설치할 것은 없고, 어떤 사이트에서나 씁니다.

1. 3분 요약

  1. 바탕화면 화면주석-QA.exe 를 두 번 클릭합니다. 처음에 파란 경고창이 나오면 [추가 정보] → [실행]. 서명이 없는 프로그램이라 그렇습니다.
  2. 주소를 확인하고 QA 시작 — 브라우저가 열립니다. 처음 한 번만 로그인하면 다음부터 유지됩니다(전용 창이라 평소 브라우저와 무관).
  3. 화면 우측 아래의 둥근 버튼을 눌러 주석 모드를 켭니다. (아래 그림)
  4. 고칠 곳을 클릭하고 메모를 적습니다. 번호 핀이 찍힙니다.
  5. 여러 화면을 돌아다니며 계속 남깁니다. 화면을 옮겨도 다시 켤 필요 없습니다.
  6. 끝나면 프로그램 창에서 클립보드 복사 → 메일·메신저·이슈에 붙여넣기.
이 버튼을 찾으세요.
화면 우측 아래에 있는 검은 둥근 버튼입니다. 누르면 주석 모드가 켜집니다.
주석을 남기면 이 버튼에 개수가 배지로 표시됩니다.
이것만 기억하세요. ①exe 두 번 클릭 → ②[QA 시작] → ③우측 아래 둥근 버튼 → ④클릭하고 메모 → ⑤[클립보드 복사]

2. 주석 도구 — 버튼이 무엇인지

둥근 버튼을 누르면 이렇게 펼쳐집니다(실제 화면 캡처).
아이콘무엇을 하나
애니메이션 정지 움직이는 배너·로딩이 있으면 멈춰 놓고 지적합니다. 다시 누르면 재생.
레이아웃 모드 요소를 직접 옮기거나 크기를 바꿔 원하는 배치를 보여 줍니다(6절 ⑤).
핀 숨기기 / 보이기 스크린샷 찍을 때 번호 핀만 잠깐 감춥니다. 지워지는 것이 아닙니다.
피드백 복사 이 화면에서 남긴 것만 글로 복사합니다. 전체는 프로그램 창의 [클립보드 복사]
전체 지우기 이 화면의 주석을 모두 지웁니다. X
프로그램 목록에서도 함께 사라집니다 — 한쪽에만 남지 않습니다.
설정 출력 상세도·핀 색상 등(5절).
나가기 (접기) 주석 모드를 끄고 둥근 버튼으로 접습니다. Esc

연동(MCP·웹훅)을 설정하면 주석 보내기 버튼이 하나 더 생깁니다. QA 는 쓰지 않아도 됩니다.

단축키

Esc 취소·모드 끄기 · Ctrl+Enter 메모 확정 · Delete / Backspace 선택한 주석 삭제

3. ★알아둘 이슈 — 주석 모드에서는 페이지 클릭이 안 됩니다

주석 모드가 켜져 있으면 페이지의 원래 클릭(메뉴·링크·버튼)이 동작하지 않습니다. 도구가 클릭을 먼저 받아 "요소를 고르는" 동작으로 쓰기 때문입니다.
다른 화면으로 가려면 Esc 를 눌러 모드를 끄고 이동하세요. 이동한 뒤 다시 켜면 됩니다.

실제로 재본 결과입니다.

상태페이지 링크·메뉴 클릭요소 주석
둥근 버튼으로 접혀 있음정상 동작(이동됨)안 됨
주석 모드 켜짐안 됨(클릭이 주석으로 감)됨
Esc 로 끈 뒤다시 정상 동작안 됨

★모달(팝업창)이 열려 있을 때

모달 안의 요소에도 주석을 달 수 있습니다. 순서만 지켜 주세요.

  1. Esc 로 주석 모드를 끄고 모달을 엽니다. (모드가 켜져 있으면 모달을 여는 버튼도 눌리지 않습니다 — 위 표와 같은 이유)
  2. 모달이 열린 상태에서 우측 아래 둥근 버튼을 눌러 주석 모드를 켭니다.
  3. 모달 안을 클릭해 메모를 남깁니다.
모달이 열려 있는 동안에는 Esc 가 모달을 닫지 않습니다. 지적하려던 모달이 사라지지 않도록 도구가 막습니다. 모달을 닫을 때는 먼저 주석 모드를 끄고 (툴바의 나가기) 모달의 닫기 버튼을 누르세요.

실제로 재본 결과입니다.

모달 종류모달 안 요소 주석
일반적인 팝업(화면을 덮는 층으로 만든 것)됩니다
아주 높은 층에 올린 팝업됩니다
브라우저 기본 팝업(<dialog>)됩니다

도구가 화면의 가장 위 층으로 올라가 모달 위에 서기 때문입니다. 모달이 열리고 도구가 그 위로 올라가는 데 0.2초쯤 걸립니다 — 툴바가 눌리지 않으면 잠깐 기다리세요.

안 되는 경우도 있습니다. 팝업이 스스로를 "팝업입니다" 라고 표시하지 않으면 도구가 알아보지 못해 Esc 가 그 팝업을 닫아 버립니다. 그럴 때는 Esc 대신 툴바의 나가기 로 모드를 끄세요.
또 팝업 안이 또 다른 iframe 인 경우에는 그 안쪽 요소를 고를 수 없습니다 — 팝업 바깥 영역에 주석을 남기고 메모에 적어 주세요.

관리자 화면(좌측 메뉴가 있는 구조)은 조금 다릅니다

내용이 iframe 안에 있는 구조에서는 내용 영역만 클릭이 막힙니다.

  • 좌측 메뉴·상단바는 주석 모드에서도 그대로 눌립니다 → 모드를 끄지 않고 화면을 옮겨 다닐 수 있습니다. (실측 확인)
  • 대신 좌측 메뉴·상단바 자체에는 주석을 달 수 없습니다. 도구가 내용 영역을 담당하기 때문입니다. 그 부분을 지적할 때는 내용 영역에 주석을 남기고 메모에 "좌측 사이드바 …" 라고 적어 주세요. 이게 불편하면 도구를 상단으로 옮기는 방식을 추가할 수 있습니다 — 요청해 주세요.
메뉴가 자꾸 눌려서 방해될 때는 반대로 설정의 페이지 클릭 차단을 켜세요. 모드를 끈 상태에서도 페이지 클릭이 막혀, 실수로 화면이 넘어가는 것을 막습니다.
지우면 양쪽이 같이 지워집니다. 어느 쪽에서 지워도 다른 쪽에 남지 않습니다.
어디서 지우나이 화면의 핀프로그램 목록
툴바의 전체 지우기사라짐사라짐(그 화면 것만)
주석 하나 선택 + Delete사라짐사라짐(그 하나만)
프로그램의 비우기사라짐사라짐(모든 화면)
프로그램의 추출사라짐파일로 저장한 뒤 사라짐
창 크기나 확대 비율을 바꾼 뒤에 지워도 그 화면의 기록은 전부 지워집니다.

4. 프로그램 창 (왼쪽 큰 창)

테스트할 주소검사할 사이트 주소. 마지막에 쓴 주소를 기억합니다.
QA 시작브라우저를 엽니다. 이미 열려 있으면 그 창을 입력한 주소로 이동시킵니다.
오른쪽 위 배지주입됨 = 주석 도구가 떠 있음. 주입 대기 = 준비 중(2~3초). 프로그램이 스스로 확인해 표시합니다.
목록남긴 주석이 화면별로 쌓입니다. 화면·제목·해상도·주소·주석 수·그 화면의 오류 수.
화면 왼쪽의 화살표를 누르면 그 화면의 주석이 펼쳐집니다.
주석 줄 더블클릭보강 창이 열립니다(6절 ⑦). 보충 메모를 덧붙이거나, 다른 화면의 주석과 연결할 수 있습니다. 브라우저에서 적은 원래 메모는 여기서 고치지 않습니다 — 그건 화면의 핀을 눌러 고칩니다.
클립보드 복사전체를 글로 만들어 클립보드에 담습니다. 프로그램을 닫아도 유지됩니다.
누르면 먼저 총평을 물어봅니다 — 없으면 [건너뛰기].
추출 (저장 후 삭제)파일로 저장하고 목록을 비웁니다. 저장이 실패하면 목록을 그대로 둡니다.
비우기 (보관)목록을 비웁니다. 원본은 결과 폴더의 archive 에 남습니다. 브라우저에 남은 핀도 함께 사라집니다.
결과 폴더결과 파일이 있는 폴더를 엽니다.
사용법이 문서를 엽니다.
진행 상황지금 무엇이 되고 있는지 알려 주는 기록. 문제가 생기면 이 내용을 그대로 전달해 주세요.
같은 주소가 두 줄로 보일 때가 있습니다. 브라우저 창 크기나 확대 비율이 달라지면 레이아웃이 달라지므로 다른 화면으로 셉니다. "1920에서는 정상인데 1366에서 깨진다"가 그대로 남습니다.

5. 설정

출력 상세도간단 / 표준 / 상세 / 정밀. 개발자가 원인을 못 찾겠다고 하면 상세로 올려 다시 보내세요.
핀 색상화면 색과 겹쳐 핀이 안 보일 때 바꿉니다.
복사·전송 후 자동 비우기복사하면 그 화면 주석을 자동으로 정리합니다.
페이지 클릭 차단모드를 끈 상태에서도 페이지 클릭을 막습니다. 실수로 화면이 넘어가는 것을 방지.
새 탭까지 숨기기잠깐 도구를 감춥니다.
MCP·웹훅개발 연동용입니다. QA 는 쓰지 않아도 됩니다.

6. 영역별로 어떻게 남기나

① 버튼·글자·이미지 하나 — 그냥 클릭

마우스를 올리면 테두리와 요소 이름이 보입니다. 원하는 것에 테두리가 걸렸을 때 클릭하고 메모를 적습니다.

  • 원하는 것보다 큰 영역이 잡히면 조금 안쪽으로 옮겨 다시 올려 보세요(작은 요소가 먼저 잡힙니다).
  • 표(그리드)의 칸 하나도 잡히고, 그 칸의 좌우 값까지 함께 기록됩니다.

함께 남는 것: 요소 이름 · CSS 경로 · 클래스 · 위치와 크기 · 글꼴/크기/색 · 주변 텍스트

② 여러 개를 묶어서 / 빈 공간 — 드래그

빈 곳부터 사각형으로 끌면 그 안에 든 요소들이 한 덩이로 잡힙니다. "이 카드 3개 정렬이 안 맞음", "이 영역 여백이 너무 넓음" 처럼 배치·간격 지적에 씁니다.

③ 문구를 콕 집어서 — 글자 선택

글자를 마우스로 드래그해 선택한 뒤 남기면 그 문구가 그대로 첨부됩니다. 오타·띄어쓰기·어색한 표현에 가장 좋습니다.

④ "여기서 저기로" — 화살표·자유 그림

주석 모드에서 끌어서 그리면 화살표나 동그라미로 표시됩니다. "이 버튼을 이쪽으로 옮겨 주세요" 처럼 이동·순서를 말할 때 씁니다. 결과에는 화살표: A → B, 원으로 표시: … 처럼 글로 남습니다.

⑤ 배치를 직접 바꿔 보여 주기 — 레이아웃 모드

기존 요소를 끌어 옮기거나 크기를 바꿔 원하는 모양을 만들어 보여 줍니다. 결과에는 제안: 이동, 제안: 크기 변경 으로 남습니다. 화면이 실제로 바뀌는 것은 아닙니다 — 새로고침하면 원래대로.

⑥ 아직 없는 화면을 설명하기 — 와이어프레임 모드

빈 캔버스에 블록을 끌어다 놓아 새 화면 초안을 그립니다. "이런 화면이 필요합니다" 를 말로 설명하기 어려울 때 씁니다.

⑦ 앞뒤 사정을 덧붙이기 · 다른 화면과 엮기 — 프로그램 창에서

화면을 옮겨 다니며 조작하다 보면 원인이 다른 화면에 있는 경우가 많습니다. 예: "A 화면의 이 값이 틀린 것은 B 화면의 저장 기능 때문". 그럴 때 프로그램 창에서 엮습니다.

  1. 목록에서 화면을 펼쳐 주석 줄을 더블클릭합니다.
  2. 우선순위를 고르고, 기대에 "이렇게 되어야 합니다" 를 적습니다. 화면에서 적은 메모가 현재, 여기가 기대 입니다 — 받는 사람이 되묻지 않습니다.
  3. 보충 메모에 앞뒤 조작·재현 조건을 적습니다.
  4. [연결 추가] 로 원인이 되는 다른 주석을 고릅니다.

결과 문서에는 양쪽 모두에 서로를 가리키는 줄이 들어갑니다 — 어느 쪽을 먼저 읽어도 관계가 보입니다. 목록에는 ✎(보충 있음) · ↔숫자(연결 수) 로 표시됩니다.

주석마다 남긴 시각도 결과에 함께 적힙니다 — 이어지는 조작의 순서가 그대로 남습니다.

어떤 것을 쓸지 모르겠으면 ①과 ③만 쓰세요. 실제 QA 의 대부분은 그 둘로 끝납니다.

8. 이럴 때는 이렇게

메뉴·링크가 안 눌린다 주석 모드가 켜져 있는 것입니다. Esc 로 끄고 이동하세요(3절). 관리자 화면이면 좌측 메뉴는 그대로 눌립니다.
우측 아래 버튼이 안 보인다 2~3초 기다려 보세요. 그래도 없으면 배지가 주입됨 인지 확인 → 아니면 QA 시작 을 한 번 더. 브라우저 설정 페이지(chrome://…)나 PDF 화면에서는 뜨지 않습니다.
목록에 안 쌓인다 주석 도구가 프로그램이 띄운 창에 있어야 합니다. 평소 쓰는 브라우저 창에서는 수집되지 않습니다.
지난 주석·핀이 계속 보인다 비우기 를 한 번 누르세요. 프로그램과 브라우저 양쪽이 함께 비워집니다.
"이미 실행 중입니다" 창이 하나만 떠야 합니다(여러 개면 결과가 섞입니다). 작업표시줄의 기존 창을 쓰세요.
"전용 브라우저가 이미 열려 있는데…" 그 브라우저 창을 닫고 다시 QA 시작. 평소 브라우저는 닫지 않아도 됩니다.
"크롬이나 엣지를 찾지 못했습니다" 윈도우 10/11 이면 엣지가 기본으로 있습니다. 시작 메뉴에서 Edge 를 한 번 실행한 뒤 다시 시도하세요.
로그인이 풀렸다 전용 브라우저의 세션이 만료된 것입니다. 그 창에서 다시 로그인하면 이후 유지됩니다.
붙여넣었는데 비어 있다 클립보드 복사 를 다시 누르세요. 진행 상황에 "창을 닫아도 유지됩니다" 가 찍히면 정상입니다.
핀 위치가 살짝 어긋난다 페이지를 스크롤하거나 창 크기를 바꾸면 그럴 수 있습니다. 메모 내용과 기록된 CSS 경로는 정확하니 전달에는 문제가 없습니다.
모달(팝업) 안을 못 고른다 팝업을 먼저 열고 그다음에 주석 모드를 켜세요(3절). 켠 뒤 1초쯤 기다리면 도구가 팝업 위로 올라갑니다. 팝업 안이 또 다른 iframe 이면 고를 수 없습니다.
Esc 를 눌렀는데 아무 일도 없다 팝업이 열려 있으면 일부러 막습니다(지적하려던 팝업이 닫히지 않게). 모드를 끄려면 툴바의 나가기 를 누르세요.
그 외 오류 결과 폴더의 crash.log 와 프로그램 창의 진행 상황 내용을 그대로 전달해 주세요.

9. 알아두면 좋은 것

  • 브라우저에 설치되는 것이 없습니다 — 북마크·확장·인증서 전부 없음. 프로그램을 지우면 흔적도 끝.
  • 전용 브라우저 창이라 평소 쓰는 브라우저의 로그인·북마크와 섞이지 않습니다.
  • 어떤 사이트에서나 됩니다. 사이트에 무엇을 심지 않습니다.
  • 주석은 메모를 다는 즉시 프로그램으로 넘어갑니다. 따로 [보내기] 를 누를 필요가 없습니다.
  • 프로그램을 닫았다 켜도 지난 목록이 복원됩니다.
  • 스크린샷은 붙이지 않습니다. 그림 대신 CSS 경로·좌표·계산된 스타일·정렬 숫자로 넘깁니다 — 개발자·AI 가 그 값으로 코드를 찾습니다. 그림을 따로 붙이실 필요가 없습니다.
