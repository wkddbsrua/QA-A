# 화면 주석 QA

비개발자(QA)가 **어떤 사이트에서든** 화면을 클릭해 지적을 남기고, 그것을 셀렉터·좌표·계산된
스타일이 붙은 데이터로 넘기는 도구. UI·기능은 [agentation](https://www.agentation.com) 원본을
그대로 쓰고 **화면 문구만 한글로** 바꾼다.

## 쓰는 사람 입장

1. `화면주석-QA.exe` 더블클릭
2. 주소를 붙여넣고 **[QA 시작]** → 브라우저가 열린다
3. 화면을 클릭해 메모를 남긴다. **페이지를 옮겨도 누를 것이 없다**(툴바가 자동으로 뜬다)
4. 끝나면 **[클립보드 복사]** 또는 **[추출]**

브라우저에 설치되는 것은 **없다** — 북마크·확장·유저스크립트·인증서 전부 없음.
전용 프로필로 열리므로 처음 한 번만 로그인하면 그다음부터 유지된다.

## 왜 이 구조인가 (되돌아가지 않기 위한 기록)

이전에는 북마크릿으로 주입했다. 북마크릿은 구조적으로 두 가지를 못 한다.

| 북마크릿의 한계 | 그래서 붙었던 우회물 |
|---|---|
| 페이지를 옮기면 새 문서 → 사람이 그 화면에서 다시 클릭 | 확장 자동설치(크롬 136+ 차단) → 유저스크립트 → exe 로 북마크 자동등록 |
| 페이지 안에서 실행 → https 화면에서 로컬 수집이 mixed content 로 차단 | 로컬 싱크서버 → 확장 relay → [주석 모으기] 북마크 추가 |

그 우회물이 무거워지자 원본을 버리고 자작 주석기까지 만들었다. **원인은 하나였다 — 주입 경로.**
프로그램이 브라우저를 띄워 CDP 로 주입하면 두 한계가 동시에 사라지고 우회물 전부가 필요 없어진다.

```
[QA 시작] → 브라우저 실행(전용 프로필 + --remote-debugging-port)
          → Page.addScriptToEvaluateOnNewDocument : 모든 새 문서·하위 프레임에 자동 실행
          → Runtime.addBinding('__qaPush') : 주석이 네트워크를 타지 않고 곧장 프로그램으로
```

* 브라우저 설치물 **0** · 페이지당 클릭 **0** · https 정상(mixed content 개념이 성립하지 않음)
* iframe(셸 구조) 자동 — 예전 로더의 1.5초 폴링 해킹이 사라졌다

**여기에 VRT(해상도 순회·캡처 비교)를 넣지 않는다.** 그건 별개 도구가 하는 일이고,
넣으면 한 가지 일을 하는 도구가 또 둘로 갈라진다. 이 도구는 주석만 한다.

## iframe(셸 구조)에서 지킬 것 — 여기서 다 깨졌다

관리자 화면이 `<iframe>` 안에 있는 구조(`/shell` 같은 것)에서 문제가 몰렸다. 손대기 전에 읽을 것.

1. **툴바는 탭마다 하나.** 화면을 지배하는 프레임이 갖는다(부모는 절반 이상 차지하는 같은
   출처 iframe 에 양보, 자식은 그만큼 클 때만 갖는다). 부모·자식이 각각 띄우면 화면상 같은
   자리에 겹치고, 무엇보다 **부모의 전체화면 오버레이가 콘텐츠 클릭을 가로채** iframe 안
   요소를 아예 고를 수 없다.
2. **"떠 있는가" 를 `window` 플래그로 판단하지 말 것.** iframe 은 빈 문서(about:blank)로 먼저
   만들어지고 곧 실제 주소로 바뀌는데 크롬이 **window 를 재사용**한다 → DOM 은 날아가고
   플래그만 남는다. 반드시 DOM(호스트 요소 존재)으로 판단한다.
3. **한 인스턴스는 자기 문서만 담당**(`document !== myDoc` 이면 손을 뗀다). 옛 문서의 타이머가
   살아남아 새 문서에 마크업만 다시 그리면, 스타일은 이미 넣었다고 여겨 다시 넣지 않는다 →
   CSS 없는 툴바가 `position:static` 으로 문서 맨 아래에 깔린다(요소 128개, `<style>` 0개).
4. **`Page.addScriptToEvaluateOnNewDocument` 만 믿지 말 것.** iframe 의 실제 문서에는 걸리지
   않는 경우가 있다. 문서마다 표식(`document.__qaDoc`)을 남기고, 실행 컨텍스트가 생길 때마다
   확인해 빠진 문서에는 프로그램이 직접 넣는다(두 번 들어가도 2번 규칙이 막아 준다).
5. **`Runtime.evaluate` 는 contextId 를 줘야 그 프레임에 들어간다.** 안 주면 최상위 프레임뿐이다.
6. **자가확인은 프레임 전체를, 그리고 "실제로 고정 배치돼 보이는가" 까지** 본다. 호스트 요소
   존재만 보면 CSS 없이 깔린 상태를 "주입됨" 으로 오보고한다(실제로 그랬다).
7. **진단은 숫자로.** 래퍼가 `document.__qaDoc`/`window.__qaInjected`/`window.__qaReady` 를
   남긴다. "툴바가 안 뜬다" 를 추측하지 말고 이 값을 읽어 *주입이 안 온 것*과 *마운트 판단
   문제*를 가른다.

## 모달 위로 올라가기 — z-index 경쟁을 하지 않는다

"모달이 열리면 요소를 고를 수 없다" 를 고친 기록. **z-index 를 올리는 방향으로 되돌아가지 않는다.**

우리 UI 의 최대 z-index 는 100020 이고 페이지는 `2147483647` 을 쓸 수 있다. 사이트별로 숫자를
맞추는 길은 "어떤 사이트에서나" 와 양립하지 않는다. 그래서 **층을 떠나 top layer 로 올라간다** —
top layer 는 정의상 모든 z-index 보다 위여서 경쟁이 성립하지 않는다.

CDP 로 진짜 마우스 클릭을 보내 카운터로 확인한 결과(크롬 151):

| 우리 UI | 방해물 | 클릭이 우리에게 오나 |
|---|---|---|
| 보통 요소(z=100020) | 페이지 오버레이 `z-index:2147483647` | **안 온다** |
| `popover`(top layer) | 같은 오버레이 | **온다** |
| `popover`(top layer) | `dialog.showModal()` | **안 온다** — top layer 안에서도 모달이 최상위고 나머지는 `inert` (여는 순서와 무관) |
| 모달 dialog **안으로 옮긴 UI** | `dialog.showModal()` | **온다** — 클릭·React 이벤트 위임·`position:fixed` 좌표 모두 정상 |

그래서 `src/inject.jsx` 는 이렇게 한다.

1. UI 를 담는 투명한 틀(`#__qa_top_layer`)을 만들어 `popover=manual` 로 **top layer 에 올린다.**
   agentation 이 `document.body` 로 포털한 래퍼를 그 틀 안으로 모은다.
2. **native 모달이 열리면 틀을 그 `<dialog>` 안으로 옮긴다**(`inert` 를 면제받는 유일한 자리).
   닫히면 `body` 로 돌려놓는다. 감지는 `open` 속성 MutationObserver + 클릭 훅 + 주기 검사 —
   **모달이 열린 뒤 0.2초 안에** 올라간다(실측).
3. ★`popover` 승격이 실패하면 **속성을 반드시 떼야 한다.** 속성이 붙은 채 `showPopover()` 가
   안 되면 UA 스타일이 `display:none` 으로 만들어 **툴바가 통째로 사라진다** — 이 도구에서 가장
   나쁜 결과다. 그래서 성공을 `:popover-open` 으로 확인하고, 아니면 되돌린다.
4. **페이지의 모달은 건드리지 않는다.** `showModal` 을 `show` 로 바꿔치기하는 방법도 통하지만
   (실측), 백드롭·포커스 트랩이 사라져 QA 가 보는 화면이 실제와 달라진다. 마지막 수단으로도 쓰지 않는다.

`Esc` 도 같이 고쳤다. 사용법이 안내하는 "Esc 로 모드 끄기" 가 **지적하려던 모달을 함께 닫아
버렸다**(대상 CMS 는 Esc 로 최상위 모달을 닫는다). 주석 모드가 켜져 있고 모달이 열려 있으면
capture 단계에서 Esc 를 페이지로 넘기지 않는다. 모달 판정은 **표준 신호**(`dialog[open]` ·
`aria-modal` · `role=dialog`)로만 한다 — 그 표시가 없는 모달은 가려낼 수 없고, 그 한계를
사용법에 적어 두었다(모드 끄기는 툴바 `[나가기]`).

진단은 숫자로: `window.__qaTop()` 이 틀의 위치·popover 상태·모달 여부·모드 여부·호출 통계를 준다.

## 기기마다 다른 것을 전제로 만든 부분

이 PC 에 다 깔려 있어도 다른 PC 에는 없거나 다르다. 그래서:

| 축 | 어떻게 다루나 |
|---|---|
| 브라우저 | 표준경로 → App Paths 레지스트리 → PATH 순으로 크롬·엣지를 찾는다. 못 찾으면 조치 문장을 띄운다(윈도우 10/11 이면 엣지는 기본 탑재) |
| 파이썬·node·esbuild | **배포 PC 에 불필요.** exe 안에는 이미 만들어진 산출물만 들어간다(`build_exe.py` 가 빌드 전에 검사) |
| 화면 해상도 | **화면 하나의 정체성 = (주소, 해상도).** URL 로만 묶으면 1920 데스크톱과 1366 노트북 결과가 합쳐지고 해상도가 덮어써져 "어디서 깨졌는지"가 사라진다. 창 크기를 바꾸면 새 화면으로 센다 |
| 화면 배율(DPI) | 창 생성 전에 DPI 인식을 켠다. 안 켜면 125·150·200% 화면에서 창 전체가 흐릿하게 확대된다 |
| 창 크기 | 실제 화면 크기에 맞춰 접어 넣고 가운데 정렬(800×600 까지 확인) |
| 폰트 | 맑은 고딕 → Malgun Gothic → Segoe UI → Noto Sans KR 순으로 설치된 것을 고른다 |
| 저장 위치 | `%LOCALAPPDATA%\qa-annotator` (exe 옆에 쓰지 않는다 — USB·읽기전용 공유에서도 동작). 네트워크·로밍 경로면 SQLite 를 WAL 대신 DELETE 저널로 연다 |
| Jira 토큰 | DPAPI 로 **사용자·PC 단위** 암호화(`jira.json`). 다른 PC·계정으로 복사하면 못 푼다 — 사람마다 자기 토큰을 넣는다 |
| 포트 | 매번 빈 포트를 받는다(고정 포트 없음) |

## 사용자용 문서

`docs/사용법.html` — exe 에 동봉되고, 창 오른쪽 위 **[사용법]** 버튼이 이를 `%LOCALAPPDATA%` 로
꺼내 기본 브라우저로 연다.

구성(9절): 흐름 그림 → 시작하기 → **화면에 주석 남기기**(hover·memo 그림) →
**팝업(모달)** → 관리자 화면(툴바 위치 표) → **프로그램 창**(목록 그림) →
**보강 창**(기대·우선순위·연결 그림) → 결과에 담기는 것 → 막힐 때 → 알아두면 좋은 것.

**읽는 사람 기준으로 줄였다.** 툴바 아이콘 8개 표 · 설정 항목 표 · 지우기 대조표 ·
영역별 방법 6가지는 **뺐다** — 실사용에서 쓰이지 않고 문서만 길어졌다. 대신
"이렇게 하면 → 이렇게 됩니다" 표 4줄로 줄이고 **그림으로 대체**했다.

**고치는 방법**: `docs/사용법.src.html` 을 고치고 `python docs/make_help.py` → `docs/사용법.html`.
직접 `사용법.html` 을 고치면 다음 생성에서 덮어써진다.

* 그림은 **실제 화면을 캡처한 것**이고 `docs/icons/*.png` 에 있다. `{{img:파일명}}` 자리를
  make_help.py 가 **data URI 로 박는다** — [사용법] 은 HTML 한 개만 꺼내 열기 때문에 바깥
  파일을 참조하면 그림이 깨진다(한 파일로 자립해야 한다).
* 전체 흐름은 **인라인 SVG** 로 그렸다(그림 파일이 아니다) — 문구를 고칠 때 캡처를 다시
  뜨지 않아도 되고 무게도 0 이다.
* 그림을 다시 뽑을 때: 스크래치패드의 `capture_browser.py`(브라우저 쪽 `hover`·`memo` —
  CDP `Page.captureScreenshot`) · PowerShell 창 캡처(프로그램 쪽 `app-list`·`app-detail` —
  `EnumWindows` 로 창을 찾아 `CopyFromScreen`. 보강 창은 **주 창이 아니라서**
  `MainWindowTitle` 로는 안 찾아진다).
* ★**자르지 말 것.** 메모 팝업은 화면 오른쪽까지 걸쳐 있어 잘라내면 [추가] 버튼이 날아간다
  (실제로 그랬다). 전체 화면을 **배율 1.2** 로 뜬다 — 2배는 문서가 368KB 까지 커졌다.
* 쓰지 않게 된 `toolbar.png`·`icon0*.png` 는 남겨 둔다(다시 아이콘 표가 필요해질 때를 위해).
  make_help.py 는 **문서가 참조하는 그림만** 박는다.

## 그 밖에 지킬 것

* ★**클립보드는 반드시 네이티브(Windows API)로 쓴다.** `tkinter` 의 `clipboard_append` 는 Tk 가
  클립보드를 소유하는 방식이라 **프로그램을 닫으면 내용이 사라진다**(실측). QA 의 실제 동작은
  "복사 → 프로그램 닫기 → 붙여넣기" 이므로 그대로 두면 매번 잃는다. `set_clipboard()` 를 쓰고
  실패할 때만 tk 로 폴백한다(그 경우엔 "닫지 마세요" 를 로그로 알린다).

* **프로그램은 한 번에 하나만 돈다**(Windows named mutex). 사람들은 아이콘을 여러 번 누른다 —
  여러 개가 뜨면 각자 브라우저에 주입을 등록하고 같은 결과 파일에 쓴다(실제로 4개가 떠 있었다).
* **프로그램을 다시 켰는데 브라우저가 아직 떠 있는 경우**가 흔하다. 같은 프로필로 크롬을 또
  띄우면 크롬은 기존 창에 넘기고 스스로 종료하므로 새 포트가 열리지 않는다. 그래서 우리가
  포트를 `session.json` 에 적어 두고 **기존 창에 다시 붙는다**(크롬의 `DevToolsActivePort` 는
  넘어간 프로세스가 지워 버려 2순위).
* **기동 중을 "닫힘" 으로 판단하지 말 것.** `alive()` 가 CDP 기준이므로, 아직 붙기 전에는
  살아 있는 것으로 봐야 한다. 안 그러면 창의 주기 갱신이 기동을 취소한다(실측).
* **테스트는 스크래치패드 전용 폴더로만.** 개발 중 `%LOCALAPPDATA%\qa-annotator\out` 에 테스트
  주석을 남겨 사용자 결과에 섞인 일이 있었다.

## 결과

`%LOCALAPPDATA%\qa-annotator\out\`

* `latest.md` — 화면별로 묶인 전달용 문서. 화면마다 주소·해상도·DPR·시각 + 주석 + 그 화면의
  콘솔 에러·실패한 요청. 맨 앞에 **총평**(추출·복사 때 사람이 적는 마지막 코멘트),
  주석마다 **시각**·**보충**·**하위**(다른 주석과의 하위 관계, 3차부터 "관련" 대신)
* `qa.sqlite` — 이벤트 원본을 **회차별로** 담는 저장소(1.2). 프로그램을 다시 켜면 현재 회차를 재생해
  목록을 복원한다. 1.1 까지의 `annotations.jsonl`·`archive/` 는 첫 실행에 회차로 옮겨지고

### 되묻지 않게 하려고 결과에 넣은 것 2가지

* **`- 응답:`** — 실패한 요청 밑에 서버가 적어 보낸 **사유 본문** 앞 300자.
  상태코드만으로는 받는 쪽이 원인을 읽을 수 없다(실측: `POST …/area/fill → 400` 만 있고
  *"이미 콘텐츠가 배치된 영역입니다"* 라는 본문이 빠져 있어, 왜 막혔는지를 되물어야 했다).
  HTML 오류 페이지는 버린다 — 톰캣 기본 페이지에는 사유가 없고 태그만 길다.
  ★`Network.getResponseBody` 는 **응답을 기다리는 호출**이라 CDP 수신 스레드에서 그대로
  부르면 수신이 멈춰 데드락이 된다. 반드시 작업 큐(`_jobs`)로 넘긴다.
* **`- 속성:`** — 주석이 가리키는 요소의 속성(`data-*`·`title`·`href`…, `class`·`style` 제외).
  화면에 무엇이 **표시되는가** 가 아니라 무엇이 **와 있는가** 라서, 같은 증상이라도
  **화면 탓인지 서버 탓인지**가 여기서 갈린다. 요소를 되찾지 못하면 **붙이지 않는다** —
  엉뚱한 요소의 속성을 붙이는 것은 아무것도 안 붙이는 것보다 나쁘다(고른 지점에서 위로
  훑어 `cssClasses` 가 같은 요소를 쓰고, 없으면 경로가 **유일할 때만** 쓴다).
* **`### 이 화면의 조회 응답`** — 성공(2xx)한 XHR/fetch 중 **응답이 짧은 것만**
  본문과 함께 남긴다. *"목록이 비었다"* 류 지적에서 **조회가 0건을 낸 것인지 화면이
  걸러낸 것인지**를 가르는 근거다(실측: 위젯 목록이 비어 있다는 지적에 200 응답이
  기록되지 않아 서버·프런트 어느 쪽인지 결과 문서만으로는 알 수 없었다).
  ★**앱이 '비었다' 를 판정하지 않는다** — 무엇을 비었다고 볼지(빈 배열·`total 0`·
  페이지네이션)는 화면마다 다르다. 짧은 응답을 **그대로 보여 주고 읽는 쪽이 판단**한다.
  큰 응답을 담지 않는 이유는 두 가지다 — 비어 있을 리가 없어 진단 가치가 없고,
  전부 담으면 전달용 문서가 부풀어 붙여넣을 수 없게 된다.
  실패 목록과 **별도 목록**이다(한 목록에 담으면 성공 기록이 실패 기록을 밀어낸다).
* **`- ★재지적:`** — 닫힌 회차(1.2 부터 `annotation_versions` 의 마지막 버전, 지운 것 제외)와 **(주소, 경로)** 로 대조해, 같은 자리가 회차를
  넘겨 다시 올라오면 표시한다. *"고쳤다더니 또 안 된다"* 가 여기서 갈린다 — 지난 회차에
  고쳤다고 회신한 자리가 다시 지적되면 **원인이 그때와 다르다**는 뜻이라 회신 문안 자체가
  달라져야 한다. 대조 주소는 질의문자열만 떼고 **해시는 남긴다**(SPA 에서는 해시가 화면
  구분이라 떼면 서로 다른 화면이 한 자리로 합쳐져 오탐이 된다).

## 보충·연결·총평은 주석 '안' 에 넣지 않는다

`store.apply()` 는 브라우저가 보낸 주석 dict 를 **id 로 통째 덮어쓴다**. 주석 객체 안에 우리
필드를 넣으면 사용자가 브라우저에서 메모를 한 번 고치는 순간 날아간다. 그래서 프로그램이 쓰는
것은 별도 맵(`store.meta`) + 별도 이벤트(`{'t':'meta'}` · `{'t':'closing'}`)로 둔다.

* 연결은 **주석 id 로 저장하고 화면·주석 번호는 렌더 시점에 해석한다.** 번호를 저장하면 화면
  순서가 바뀌는 순간(되돌아온 화면·해상도 변경) 참조가 어긋난다.
* 목록(`tree_rows`)과 결과(`render`)는 **같은 `_render_pages()` 를 쓴다.** 따로 걸러 세면
  목록의 `[화면 2]` 와 문서의 `[화면 2]` 가 달라져 연결을 읽을 수 없다.
* 지운 주석의 메타는 함께 버리지만, **그것을 가리키던 연결은 남겨 `(삭제된 주석)` 으로 보여
  준다** — 조용히 사라지지 않게.
* 모르는 `t` 는 무시한다 — 옛 `jsonl` 과 앞으로의 확장 양쪽을 위해.

## 실사용자 요구를 반영한 부분 (되돌리지 않기 위한 기록)

첫 실사용 라운드에서 나온 요구를 어디에 어떻게 넣었는지. **왜 그렇게 했는지가 중요한 것들만.**

| 요구 | 구현 | 왜 그 방법인가 |
|---|---|---|
| 팝업 뒤로 툴바가 넘어가 안 눌린다 | top layer 승격(위 절) | z-index 경쟁은 구조적으로 진다 |
| 한 번 클릭에 메모창이 뜬다 → 더블클릭으로 | `src/inject.jsx` 캡처단계 click | **첫 클릭은 `stopImmediatePropagation`**(agentation 까지 차단), 두 번째는 `stopPropagation`(agentation 은 받고 페이지는 못 받음). 리스너 순서가 이 구현의 전부다 — 우리가 `start()` 에서 먼저 등록되므로 성립한다 |
| 썸네일 클릭이 미리보기를 띄운다 | 같은 리스너 | agentation 의 `blockInteractions` 는 `button·a·input·select·textarea·[role=button]·[onclick]` 만 막는다. 썸네일은 `img`/`div` + 위임 핸들러라 새어 나갔다 |
| 이동할 때 껐다 켜는 게 불편 | `Esc` 로 토글 | 켜기는 접힌 둥근 버튼을 **좌표로 찾아** 누른다(문구로 찾으면 한글화 표가 바뀔 때 조용히 깨진다). ★모달이 열려 있으면 켜지 않는다 — 그 Esc 는 모달을 닫으려는 것이다 |
| 입력 영역이 좁다 | 팝업의 textarea 를 2배 | 숫자를 박지 않고 **그때 크기의 2배**로 만든다(기기·글꼴마다 다르다). ★노드에 `data-qa-grown` 표식을 남긴다 — 팝업이 닫혔다 같은 노드로 다시 열릴 때 또 2배가 되어 폭주했다(실측 280×52 → 1169×456) |
| 팝업 버튼이 화면 밖으로 밀린다 | 뷰포트 안으로 당김 | 커진 팝업이 잘리면 확정 버튼을 못 누른다 |
| 실수로 지웠을 때 되돌리기 | `store.undo()` | **기록을 고치지 않는다.** `{'t':'skip','index':N}` 를 덧붙이고 전체를 다시 재생한다 — 원본 줄이 증거다 |
| 추출한 데이터를 다시 불러오기 | `store.load_archive()` | ~~archive 의 줄을 현재 기록에 합친다~~ **1.2 에서 뒤집었다.** 합치면 총평·순서·메타가 옛 값으로 덮이고 줄 번호 기반 되돌리기가 어긋났다("이전 내역을 찾아가면 값이 변한다"). 이제 옛 jsonl 은 **닫힌 회차로 가져오고** 읽기 전용으로 본다(아래 1.2 절) |
| 순서를 바꾸고 싶다 | 목록에서 `Ctrl+↑/↓` | 화면 그룹은 그대로 두고 **화면 안 순서만** 사람이 정한다(`{'t':'order'}`). 화면 정체성 `(주소, 해상도)` 를 건드리지 않는다 |
| 우선도로 정렬 | 목차를 우선순위순 | 본문은 화면 그룹을 유지한다. ★**미지정을 '낮음' 보다 앞**에 둔다 — '낮음' 은 나중에 해도 된다고 사람이 판단한 것이고 미지정은 아직 판단이 안 된 것이다 |
| 목록의 URL 로 이동 | 목록 우클릭 → 이 화면으로 이동 | `navigate()` 가 이미 있다 |
| 레이아웃 변경 개수를 알고 싶다 | **브라우저 화면**의 툴바 위 표시 + 프로그램 배지 | 요구가 "주석 모드에서도 알 수 있으면" 이었다 - 화면을 보는 중에 알아야 하므로 브라우저 쪽에 둔다. **누를 수 없는 표시**(`pointer-events:none`)라 툴바를 늘리지 않는다. top layer 틀 안에 있어 모달 위에서도 보인다 |
| 목록의 URL 로 이동 | **주소 열 클릭** + 우클릭 메뉴 | 요구가 "url 을 클릭하면" 이었다. 다른 열을 눌러도 이동하면 오작동이 되므로 `identify_column` 으로 주소 열만 받는다 |
| 순서를 바꾸고 싶다 (화면끼리) | 화면 줄에서 `Ctrl+↑/↓` | `{'t':'porder','keys':[…]}`. **화면 정체성 `(주소, 해상도)` 는 건드리지 않는다** — 순서만 바꾼다. 화면 번호는 렌더 시점에 다시 붙고, 하위 관계(3차부터 `- 하위:`/`- 상위:`, 당시엔 `- 관련:`)도 그때 해석하므로 참조가 어긋나지 않는다 |

### 와이어프레임 불투명도 · 툴바 위치 (2차)

| 요구 | 구현 | 왜 그 방법인가 |
|---|---|---|
| 와이어프레임이 불투명해 아래 화면이 안 보인다 | 기본값 1 → **0.5** | agentation 이 `--canvas-opacity` 로 이미 조절점을 만들어 뒀고 **사용자 슬라이더(0~1)도 있다.** 그래서 CSS 로 덮지 않았다 — 덮으면 슬라이더가 죽는다. `ko.strings.json` 의 **`patches` 절**(번역이 아닌 동작 치환, 사유 필수)에서 `useState6(1)` → `useState6(0.5)` 로 바꾼다. `build_ko.py` 가 rules 와 **따로 세고** 게이트에 함께 넣는다 |
| 와이어프레임·주석에 좌측 메뉴·상단바가 빠진다 | **툴바를 최상위 화면에 고정** 하는 스위치 | ★이중 마운트로 돌아가지 않는다(iframe 규칙 1의 사고 경로). **"lnb·gnb 포함" 과 "iframe 내부 선택" 은 동시에 성립하지 않는다** — 문서가 다르면 히트테스트가 안 된다. 그래서 사람이 고른다. 프로그램 창 체크박스 → `window.__qaForceTop` → `shouldMount()` 가 최상위만 허용 |

| 켠 것을 잊어 "gnb·lnb 만 잡히고 나머지는 안 잡힌다" 가 고장으로 읽힌다 | **툴바 위 모드 표시**(브10) | 설정은 `settings.json` 에 눌러붙는데 화면에는 단서가 하나도 없었다. 주입 배지도 못 가린다 — `check_injected()` 는 프레임 하나만 떠 있어도 초록이다. 그래서 `showModeBadge()` 가 `자동/최상위 고정 · 최상위/iframe 문서 · 판번호` 와 "지금 무엇을 고를 수 있는가" 를 툴바 위에 적는다. **버튼이 아니다**(`pointer-events:none`). 교차출처 iframe 은 `foreignFrameExists()` 로 따로 말한다 — 그 안은 그 문서의 툴바가 담당한다. 프로그램 창은 **시작할 때마다** 판·툴바 위치를 로그에 적는다 |

전환은 `launcher.set_force_top()` 이 지금 떠 있는 문서에도 바로 적용한다.
★`__qaClear` 를 쓰지 않는다 — 그것은 저장된 주석까지 지운다. 그래서 **`__qaRemount`** 를 따로 뒀다.

`Esc` 위임(셸 구조): 툴바가 없는 문서가 Esc 를 받으면 **자식·부모 양방향**으로 넘긴다.
사람이 iframe 안을 한 번 클릭하면 포커스가 그 문서로 옮겨가므로 아래로만 넘기면 안 먹는다(실측).
켤 때는 **320ms 뒤 한 번만 재시도**한다 — 툴바 등장 애니메이션 중에는 클릭이 무시된다(실측).

### 두 번째 실사용 라운드 (3차)

| 요구 | 구현 | 왜 그 방법인가 |
|---|---|---|
| 목록에서 클릭 드래그로 순서를 바꾸고 싶다 | `app.py` 트리에 `ButtonPress-1`/`B1-Motion`/`ButtonRelease-1` | 기존 `Ctrl+↑/↓` 는 그대로 둔다(한 칸씩 옮길 때 더 정확하다). 드래그는 **형제 사이에서만** 허용한다 — 화면 줄이 주석 줄 밑으로 새거나 하위 주석이 다른 부모로 넘어가면 트리 구조 자체가 깨진다. 저장은 기존 `set_order`/`reorder_pages` 를 그대로 쓴다(경로를 늘리지 않는다) |
| 메모창이 화면 경계에서 좌우로 흔들린다 | `growPopup` 의 보정을 `style.transform` 대신 **CSS `translate` 속성**으로 | agentation 의 스타일시트가 이미 `transform: translateX(-50%)` 로 가운데 정렬을 걸어 둔다. `transform` 을 직접 쓰면 그 값을 통째로 덮어써 팝업이 반 폭만큼 튄다. `translate` 는 `transform` 과 별도로 합성되는 속성이라 가운데 정렬을 살리면서 보정만 더할 수 있다. ★보정량은 **이미 보정된 rect 에서 이전 보정값을 뺀 값**으로 계산한다 — 안 그러면 매 tick 마다 "이미 당겨진 자리" 를 또 당겨 진동한다 |
| 레이아웃 모드에서 옮긴 것이 목록에 안 보인다 | `inject.jsx` 가 `agentation-rearrange-`/`agentation-design-` 를 읽어 diff(`layoutDiff`)를 계산해 `kind:'layout'` 로 보낸다 | 레이아웃 변경은 agentation 콜백으로 나오지 않고 localStorage 에만 산다 - 지금까지는 개수만 셌다(브9). 새 기능이 아니라 **agentation 이 이미 저장해 둔 것을 마저 전달**하는 것이다. `store.set_layout()` 이 전체 diff 를 **치환**한다(누적하면 되돌린 변경까지 남는다) |
| 다른 화면에서 메모를 고치면 주석이 2번씩 생긴다 | `store.apply()` 가 삽입 전에 `_find_home(aid)` 로 그 id 가 이미 사는 화면을 찾아 **그 자리에서 갱신**한다 | agentation 은 주석을 pathname 단위로 저장해 해시·쿼리·해상도가 달라도 같은 핀을 보여준다. 그 화면에서 고치면 `update` 가 다른 `(url,viewport)` 키로 와서, 그냥 삽입하면 같은 id 가 두 화면에 남았다. `delete` 도 **전 화면**에서 지우도록 넓혔다(id 는 전역 유일) |
| 연결(여러 개)·하위로 묶기·접기 | `meta.refs` 의 의미를 **"하위 주석"** 으로 바꾼다. `store._nested()` 가 부모/자식 트리를 계산해 `tree_rows`·`render` 등 다섯 곳이 같은 번호(`1.1`)를 쓰게 한다 | 요구가 "연결하면 하위로 들어가게" 였다 - 저장 형식(aid 리스트, 렌더 시점 해석)은 그대로 두고 **의미만** 바꿨다. 화면이 달라도 하위로 묶인다(연결의 목적이 "원인이 다른 화면에 있다" 이므로). 이미 부모가 있거나 순환이 되는 연결은 **조용히 사라지지 않고** `- 하위:`/`- 상위:` 줄로 남는다. 고르기 창은 `selectmode='extended'` 로 여러 개를 한 번에 묶는다 |
| 그림 첨부 | 메모창에 `paste`/`drop` 캡처 리스너, 보강 창에 첨부 절, `store.attach`(파일로만 저장, jsonl 에 base64 없음), 그림 있으면 추출을 `.zip` 으로 | 아래 "스크린샷을 붙이지 않는다" 절 참고 - **도구는 여전히 찍지 않는다.** 사람이 캡처해 붙인 그림만 받는다. 클립보드 복사에는 그림이 못 간다(글자만 담기는 통로다) - 그래서 그림이 하나라도 있으면 문서와 그림을 zip 하나로 묶어 "파일 하나만 넘기면 된다" 를 지킨다 |

### 지라에 그림 올리기 — 실측 필요

`launcher.paste_into(url, text, files=…)` 에 파일 드롭을 추가했다. 편집기 위로
`Input.dispatchDragEvent`(dragEnter→dragOver→drop, `Input.setInterceptDrags` 선행)를 흉내 내고,
그림 노드 수가 늘지 않으면 숨은 `input[type=file]` 에 `DOM.setFileInputFiles` 로 채우는 2안까지
넣었다. **아직 진짜 지라 화면에서 실측하지 못했다** — 편집기 내부 구조가 모사와 다를 수 있다.
실측 전에는 '지라에서 된다' 고 적지 않는다(위 규칙과 같다). 둘 다 안 되면 조용히 건너뛰고
글만 채운 채 끝난다 - 실패가 아니다(첨부 폴더를 열어 안내한다).

### 보내기 전 확인·수정 (프7)

복사·추출을 누르면 **총평 → 결과 문서 전문 → 확인** 순으로 간다. 그 창에서 **본문을 고칠 수 있다.**

* ★고친 내용은 **이번 복사·저장에만** 반영된다(목록은 그대로). MD 는 목록에서 만들어지는 것이라
  거꾸로 되돌릴 수 없다. 그 사실을 **창에 적어 둔다** — 숨기면 "고쳤는데 다음에 또 원래대로
  나온다" 가 된다.
* `store.export(path, text=…)` 가 확인한 텍스트를 그대로 저장한다(안 주면 지금 상태로 렌더).

**지라 자동 등록(프6)은 URL 만으로 안 된다 — 인증이 필요하다.** Atlassian Cloud 는
`이메일 + API 토큰`, 사내 서버는 PAT 다. URL 은 '어디에 쓸지' 만 주고 '쓸 권한' 은 주지 않는다.

그래서 1.1 에서는 **키 없이 가는 길**로 만들었다(`launcher.paste_into` — **2026-09-14 삭제**, 토큰 경로로 통일):

1. 그 탭으로 이슈를 **열고**
2. 댓글 편집기를 찾아(`textarea` · `[contenteditable]` · `[role=textbox]`) **내용을 채우고**
3. **[등록] 은 사람이 누른다.** 이 경로에서는 도구가 등록하지 않는다.
   (1.2 의 **토큰 경로**는 다르다 — 사람이 [보내기] 를 누르면 도구가 REST 로 등록한다. 위 1.2 절)

우리가 띄운 브라우저에 사람이 이미 로그인해 두었으므로 **그 세션을 그대로 쓴다** —
토큰을 보관하지 않고, 마지막 클릭이 사람이라 오발송이 없다.
못 채워도 실패가 아니다: 내용을 클립보드에 담고 "붙여넣고 등록하세요" 로 안내한다.

★**리치 텍스트 편집기에서는 `Input.insertText` 한 번으로 넣으면 줄바꿈이 사라진다**
(실측: 66자 문서가 59자로 — 개행 7개가 없어져 문서가 한 덩이로 붙었다).
그래서 리치일 때만 **줄 단위로 넣고 사이에 Enter 를 눌러 준다**(`_type_text`).
편집기 두 종류를 모사해 검증했다 — 줄 수 4/4 보존, `등록` 은 눌리지 않음.

**아직 실측하지 않은 것**: 진짜 지라 화면. 편집기 구조가 모사와 다를 수 있고,
마크다운 표·헤딩이 ADF 로 변환되며 깨질 수 있다 — 그때는 결과 `.md` 를 **첨부**로 올리고
댓글에는 항목 목차만 넣는 쪽이 낫다. **실측 전에는 '지라에서 된다' 고 적지 않는다.**

**아직 안 한 것**: 해시 라우팅 화면에서 콘솔·네트워크 귀속이 이전 화면에 붙는 문제.

## 회차(SQLite) · 화면 캡처 · 잘라 붙이기 · Jira 토큰 · 동영상 (1.2)

두 번째 실사용 라운드 뒤의 요구 4가지 + 추가 요구 1가지. 계획·검증 기록은 `~/.claude/plans/fuzzy-humming-snail.md`.

### 회차 — "이전 내역을 찾아가면 값이 변한다" 의 진짜 원인

저장 형식이 아니라 구조였다. ①`apply()` 가 주석을 id 로 통째 덮어써 나중 값만 남고 ②`load_archive()` 가
옛 jsonl 을 현재 뒤에 이어붙여 총평·순서·meta 가 옛 값으로 덮이고 ③`skip`(되돌리기)이 **줄 번호**라
이어붙이면 엉뚱한 줄을 무시했다. 그래서:

* `qadb.py` — `out/qa.sqlite`. 표 4개뿐이다: `rounds`(회차) · `events`(원본, append-only) · `skip`(**event id**) ·
  `annotation_versions`(주석마다 버전 append, delete/clear 는 tombstone). 화면·메타·순서·첨부·캡처는 전부
  `events` 재생으로 만든다 — **진실은 하나**(두 곳에 쓰면 어긋난다).
* [비우기]·[추출] = 현재 회차를 닫고 새 회차를 연다. 파일을 옮기지 않는다(첨부·캡처가 `r<id>/` 폴더라서).
  **지난 회차는 읽기 전용**(`RoundView`) — 쓰기 메서드는 `ReadOnlyRound` 를 던진다(조용히 무시하면 화면과
  기록이 어긋난 채 지나간다). [지난 기록] 창에서 보기 · 다시 보내기(복사·저장·이슈·Jira) · 옛 jsonl 가져오기.
* 보강 창 [변경 이력] = `annotation_versions`. 되돌린 삭제는 "취소됨" 으로 남는다.
* 마이그레이션(`qadb.migrate_legacy`)은 **한 트랜잭션**이다. 실패하면 회차가 하나도 생기지 않고 원본 이름도
  안 바꾼다 → 다음 실행에 재시도(중간까지 들어간 회차가 겹치는 일이 없다). 옛 `skip` 의 줄 번호는 물리 줄
  → event id 표로 환산한다(빈 줄·깨진 줄도 자리를 차지한다). `export_seq` 는 `rounds.seq` 로 승계.
* 검증: 실제 기록 사본(151줄 + archive 2개)으로 **옛 store 와 새 store 의 `render()` 가 동일**(시각 줄 제외),
  RoundView 2개 = archive 단독 재생과 동일, 재지적 자리 수 동일, undo 가 event id 로 정확히 마지막 삭제만 무시,
  마이그레이션 도중 실패 → 회차 0 · 재시도 → 정확히 3회차.
* **테스트 격리는 `QA_HOME`** — 지정됐는데 못 쓰면 폴백 없이 종료한다.

### 화면 단위 캡처 (핀 오버레이) — 주석별 캡처가 아니다

사용 패턴이 "화면 A 에서 3~4개, B 에서 3~4개" 라서 **화면(주소·해상도)당 1장**, 그 화면의 항목 번호
(`1`, `1.1`, `[2] 1`…)를 빨간 핀으로 겹친다. 문서의 `## N.` 과 핀 번호가 1:1 이다.

* 시점: 주 창 **[캡처 갱신]** + **보내기 전 확인 창 진입 시 자동 1회**(마지막 화면을 안 찍고 보내는 일이 없게).
  열려 있지 않은 화면은 "캡처 없음" 으로 확인 창에 뜬다 → 목록 주소를 눌러 열고 [캡처 갱신].
* 실측(크롬 151) 두 가지가 구현을 정했다. ①`Page.captureScreenshot` 의 `clip` 은 **문서 좌표**다(뷰포트가
  아니다 — 스크롤 1400 에서 문서 y=1500 을 찍으려면 clip.y=1500). ②`captureBeyondViewport` 전체 캡처에서도
  `position:fixed` 요소는 **현재 스크롤 위치**에 찍힌다. 그래서 `begin()` 이 맨 위로 스크롤한 뒤 찍고 `end()`
  가 되돌리며, 핀 컨테이너는 `position:absolute`(문서 원점)다 — fixed 로 두면 스크롤만큼 밀린다.
* 핀 위치는 `querySelectorAll(path).length===1` 일 때 지금 자리, 아니면 저장 `boundingBox`(agentation 은 y 만
  scrollY 가산, x 는 뷰포트 기준 — 스크롤 0 이면 둘 다 문서 좌표). 핀 컨테이너는 `popover` 로 top layer,
  실패하면 속성을 떼고 보통 요소로(모달 규칙과 같은 경로). 찍는 동안 툴바·agentation 핀·메모창은 `visibility:hidden`.
* iframe 화면: 핀은 그 문서 자신에 그리고(iframe 규칙), 프레임 높이를 문서 높이로 늘린 뒤(같은 출처는
  `frameElement`, 교차출처는 부모 세션 `DOM.getFrameOwner` → `callFunctionOn`) **최상위 세션**에서 찍는다.
  ★같은 프로세스의 교차출처 프레임(`file://` 끼리·사이트 격리 꺼짐)은 부모 세션이 없다 — 같은 세션의 DOM 에서
  찾는다(`_frame_owner` 가 둘 다 본다). 실측: 셸(좌측 메뉴+iframe) 캡처에서 iframe 안 (400,2600) 의 핀이
  최상위 좌표 (580,2648) 에 정확히 찍혔고 프레임 높이는 복구됐다.
* 타일: 한 장 높이 `floor(15000/dpr)` CSS px, 최대 6장, 초과는 `partial`. 한 장이 실패하면 절반으로 나눠
  1회 재시도. 파일명 `NN_<경로 slug>_<해상도>[-k].png`, `capture/r<id>/`. 렌더는 화면 블록 `- 캡처: 캡처/…`,
  찍을 때의 `{aid: label}` 을 남겨 번호가 바뀌면 `(번호 바뀜 · 캡처 갱신 필요)`.
* `Store.lock` 을 잡은 채 CDP 를 기다리지 않는다 — `capture_targets()` 로 스냅샷을 뽑고 잠금 밖에서 찍고
  `set_capture()` 로 결과만 넣는다.

### 화면에서 잘라 붙이기 (부분 캡처) — 사람이 영역을 고른다

"스크린샷 첨부를 따로도" 라는 요구. **Win+Shift+S 를 대신할 뿐** 도구가 주석마다 스스로 찍지 않는다 —
그래서 브8 '사람이 붙인 그림' 과 같은 자리(`attach` 이벤트·`attach/r<id>/`)에 들어간다.

* 시작점 둘: 메모창의 **`✂ 화면 잘라 붙이기`**(확정 전 그림 목록에 쌓여 add/update 와 함께 저장) ·
  보강 창 **[화면에서 잘라 붙이기]**(그 주석의 화면이 열려 있으면 그 문서에 선택 오버레이. 없으면 이동을 권한다).
* 브라우저는 좌표만 정한다(`push('snip', {rect, offset, top, dpr})`). 오버레이는 그 주석의 요소 박스를 **제안
  영역**으로 미리 그린다(Enter = 그대로 · 드래그 = 새 영역 · Esc = 취소). 포인터 이벤트는 document 캡처 단계에서
  가로챈다(`guardSnip` 이 `guardClicks` 보다 먼저 등록) — 드래그가 agentation 요소 고르기나 페이지로 새지 않는다.
* 파이썬이 그 탭의 **최상위 세션**에서 `clip = 뷰포트 rect + 프레임 오프셋 + 최상위 스크롤`(문서 좌표), `beyond=False`
  로 찍는다(사람이 보는 그대로 — fixed 도 제자리). 결과는 `target` 이 `'popup'` 이면 `__qaSnipDone(token, ok, dataUrl)`
  로 그 문서에 되돌려 메모창 목록에 넣고, aid 면 `store.add_image_bytes()` 로 곧장 첨부한다.
* 실측(헤드리스 크롬, 실제 agentation 툴바): 더블클릭 → 메모창 → ✂ → 드래그 100×100 → 메모창에 "그림 1장" →
  [추가] → store 에 주석 1건 + 첨부 1장. 보강 창 경로에서 마젠타 마커 영역 → PNG 100×100, 중앙 픽셀 (255,0,255).
  iframe 안 주석 → 오프셋(180,48) 반영돼 파란 상자가 찍혔다. Esc 로 취소 · 캡처 후 툴바·모드 그대로.

### Jira — 사람마다 자기 토큰 (`jira_api.py`)

* **2026-09-14: 1.1 의 브라우저 붙여넣기 경로(이슈에 올리기 · 등록은 사람이)는 뺐다** — 사내에서 전원이 토큰을
  쓰기로 해 경로를 하나로 통일했다(`launcher.paste_into`·`_drop_files`·`_media_count`·`_type_text` 삭제).
  토큰 경로는 새 이슈 생성 / 기존 이슈 댓글 + 첨부(그림·동영상·캡처)까지 REST 로 한다 — **도구가 등록한다**
  (사람이 [보내기] 를 누른 뒤). 아래 "지라 자동 등록(프6)" 절은 그 경로가 왜 그렇게 생겼었는지의 기록이다.
* 토큰은 `HOME\jira.json` 에 **DPAPI**(`CryptProtectData`, 사용자·PC 단위)로만 둔다. 파일을 다른 계정·PC 로 복사하면

* 본문은 **REST v2 + wiki markup**(v3 는 ADF 필수). `md_to_wiki()` 가 줄 단위로 옮긴다: `#`→`h1.`, `- `→`*`,
  `  - `→`**`, `1. `→`#`, `> `→`{quote}`, `**x**`→`*x*`, `` `x` ``→`{{x}}`, ```→`{code}`(안은 치환 안 함),
  `- 첨부: 첨부/x.png`→`!x.png|thumbnail!`, 동영상·기타→`[^x.mp4]`. 순서: 새 이슈 = create → 첨부. 댓글 = 첨부 → 댓글.
* 첨부는 multipart 를 직접 조립(`X-Atlassian-Token: no-check`, `filename*=UTF-8''…` + ASCII 폴백). 사이트
  `attachment/meta.uploadLimit` 초과 파일은 건너뛰고 결과창에 나열. 동영상 100MB 는 **경고 후 계속 가능**.
* **부분 성공을 숨기지 않는다.** 새 이슈 키는 만들자마자 `settings.jira_last_issue` 에 적고, 첨부 실패는 파일별로
  나열한다 — 재시도는 '기존 이슈에 댓글' 로 그 키에 첨부만 다시(중복 생성 금지). 실패 시 본문은 클립보드로.
* 실측(2026-09-11, 실제 사이트): `myself`(displayName) · `attachment/meta`(uploadLimit 500MB) · 잘못된 토큰 →
  401 문구. **실전송(2026-09-14, SC-720)**: 새 이슈(QA) + 첨부 3개(한글 파일명 유지·`image/png`·`text/plain`) →
  댓글 + 첨부 1개 → 읽어 확인. `h1.`·`h2.`·`#`·`**` 가 description 에 그대로 들어간다. 한글 파일명은
  `filename*=UTF-8''` 로 원래 이름이 보인다. wiki **렌더 모양**(썸네일·인용)은 브라우저에서 한 번 더 볼 것.
* **프로젝트·이슈 유형은 이 계정이 만들 수 있는 것만 고르게 한다**(`creatable()` = `createmeta`). `/project` 는
  볼 수 있는 90여 개를 전부 주지만 생성 권한은 12개였고, 'Jira 테스트용 프로젝트'(TEST) 조차 403 이었다.
  기본 유형은 `QA` — 사내 프로젝트는 거의 전부 `에픽·작업·자료·QA` 뿐이고 `Bug` 는 없다(옛 기본값 `Bug` 는
  첫 시도부터 400 을 냈을 것). 필수 필드가 더 있는 유형(MIMS·작업 = 고객·계약 정보 8개)은 안내만 하고 도구로 만들지
  않는다. 목록을 못 받으면(오프라인·401) 콤보에 직접 쳐서 보낸다.
* 토큰은 **한 번만** 넣는다 — `save()` 는 토큰을 주지 않으면 기존 암호문을 유지한다(보내기 창이 프로젝트를 저장하는
  경로 포함). 설정 창의 [토큰 발급 페이지 열기] 가 `id.atlassian.com` 을 기본 브라우저로 연다.

### 동영상

사람이 Windows 녹화(Win+Alt+R)로 찍은 파일을 보강 창 [파일 추가]로 붙인다. 도구는 녹화하지 않는다.
`store.attach_kind()` 가 확장자로 가르고 목록에 `(동영상 · 12.3 MB)`, 문서에 `- 첨부: 첨부/x.mp4 (동영상 12.3 MB)`.
zip·Jira 경로는 첨부 목록을 그대로 탄다(`inject.jsx` 의 `imageFilesOf` 는 여전히 그림만 받는다).

## 스크린샷을 붙이지 않는다 — 그래서 텍스트가 그림의 일을 해야 한다

★**도구가 주석마다 스크린샷을 찍는 기능은 넣지 않는다.** 스크린샷 첨부를 없애려고 만든 도구다
(셀렉터·좌표·계산된 스타일로 넘긴다). 도구가 화면을 대신 찍으면 이 도구의 존재 이유가 사라진다 —
**회귀다.**

★**사람이 캡처해 붙인 그림(브8)은 다르다.** 색·배치처럼 글로 옮기기 힘든 지적에서, QA 가
**직접 잘라 온** 그림 한 장이 문장 여러 줄보다 빠를 때가 있다. 그래서 메모창에 `Ctrl+V`/드래그로
붙이는 길을 열어 뒀고, 1.2 에서 **화면에서 잘라 붙이기**(영역을 드래그해 고른다)를 더했다 —
**무엇을 얼마나 보여줄지는 여전히 사람이 고른다.** 주석마다 도구가 스스로 찍는 버튼은 두지 않는다.
1.2 의 **화면 단위 캡처**는 주석별이 아니라 화면당 1장(핀 오버레이)이라 이 규칙과 충돌하지 않는다(위 1.2 절).
이 그림들은 클립보드 복사에는 따라가지 않는다(글자만 담는 통로다) - 추출(zip)·Jira 로만
전달되어, "그림 없이 텍스트로 충분하다" 는 기본 경로를 건드리지 않는다.

그래서 "그림을 보내 달라" 는 말이 나오는 쪽을 텍스트로 막는다. 실제 QA 회신에서 나온 요구를
도구가 스스로 처리하게 옮긴 것:

| QA 가 되묻던 것 | 도구가 하는 일 |
|---|---|
| "다크에서 캡처한 색값인지 몰라 색 지적의 기준이 어긋난다" | 화면마다 **`- 색 기준:`** — 배경색·`color-scheme`·브라우저 선호를 적는다. 테마를 강제하지는 않는다(할 수 없다) |
| "정렬이 안 맞는다 를 글로는 못 읽는다" | 묶어 잡은 주석에 **`- 정렬:` `- 크기:` `- 세로 간격:`** — 좌/우 x, 폭·높이, 인접 간격을 숫자와 최대 차이로 낸다(`elementBoundingBoxes` 는 지금까지 버려지고 있었다) |
| "안쪽으로 옮겨 달라 의 기준이 없다" | **`- 배치:`** — `display`·`padding`·`gap`·정렬·테두리·`z-index`·`overflow` 를 뽑아 세운다. **기본값은 빼고** 낸다(실측: `flex-direction: row` 와 `text-align: start` 가 전 항목에 붙어 아무것도 말해 주지 않으면서 줄의 절반을 먹고 있었다) |
| "색·글자 값이 문장 중간에서 끊겨 못 읽는다" | **`- 색:`** · **`- 글자:`** — 예전 `- 스타일:` 은 원본을 300자에서 통째로 잘랐고, `font-family` 목록이 앞을 먹어 매번 중간에서 끊겼다. 같은 정보를 **배치·색·글자 세 줄**로 나눠 전부 읽히게 한다(글꼴은 첫 하나만) |
| "지금 어떻고 어떻게 되어야 하나" | 주석 메모가 **현재**, 프로그램에서 적는 **`- 기대:`** 가 기대. **`- 우선순위:`** 도 함께 |
| "이슈 댓글이 '첨부하였습니다' 한 줄이라 검색에 안 걸린다" | 문서 맨 앞 **`## 항목 N건`** — 한 줄씩이라 댓글에 그대로 붙인다 |

## 개발 (빌드 PC 에서만)

```
python build_ko.py       # 번역 적용 + 게이트 3종. 실패하면 종료코드 1
python build_inject.py   # esbuild 번들 → DOM 준비 후 실행하도록 감쌈
python build_exe.py      # release/화면주석-QA.exe (+ 바탕화면 복사)
```

`build_ko.py` 의 게이트는 숫자로 증명한다 — **못 찾음 0 · 개수 불일치 0 · 잔존 영문 UI 0**.
"꼼꼼히 봤다"는 지킨 척이 가능하지만 "잔존 0"은 파일을 조작하지 않으면 거짓말할 수 없다.
번역표는 `ko.strings.json` 하나다. 새 문구가 보이면 거기에 넣고, UI 가 아니면 `allow` 에
**사유와 함께** 등록한다(조용한 면제 금지 — 실제로 `Webhooks` 를 그렇게 놓쳤고 눈 대조에서 잡았다).

* 요소 유형명(`Button`·`Card` …)은 영문으로 남긴다 — 주석 결과의 `element` 필드에 박히고
  개발자·AI 가 그 이름으로 코드를 찾는다(`COMPONENT_MAP[type].label` 이 그대로 쓰인다).
* 원본 `node_modules/agentation/dist/index.mjs` 는 **읽기만** 한다. 치환은 사본에만.

## 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 프로그램 창(tkinter). 주소 입력 · 목록 · 복사/추출/비우기 |
| `launcher.py` | 브라우저 탐색·실행, 타깃 자동 부착, 주입, 콘솔·네트워크 수집 |
| `cdp.py` | CDP 클라이언트. 표준 라이브러리만(RFC6455 최소 구현) — 다른 PC 재현성을 위해 외부 의존 0 |
| `store.py` | (주소, 해상도) 단위 누적 · `latest.md` 출력 · 현재 회차 재생(복원) · 프로그램 소유 메타(보충·하위·총평) · 하위 트리(`_nested`) · 첨부(그림·동영상·잘라 붙인 것) · 화면 캡처 목록 · 레이아웃 변경 · `RoundView`(지난 회차 읽기 전용) |
| `qadb.py` | SQLite 회차 저장소(1.2). `rounds`·`events`·`skip`(event id)·`annotation_versions`. 1.1 jsonl 마이그레이션(한 트랜잭션) |
| `jira_api.py` | Jira Cloud REST v2(1.2). DPAPI 토큰 저장 · `md_to_wiki` · 이슈 생성/댓글/첨부(multipart 직접 조립) |
| `src/inject.jsx` | 주입 스크립트. agentation 마운트 + 화면 정보 통지 |
| `ko.strings.json` | 번역표(원문·한글·사유) + allow 목록 |

## 라이선스

`agentation` 은 **PolyForm Shield 1.0.0** 이다. 사내 QA 용도로 쓰고, 경쟁 제품으로 쓰지 않으며,
재배포 시 라이선스를 동봉한다. 원본 패키지는 수정하지 않고 문구만 바꾼 사본을 만들어 쓴다.

서명 없는 exe 라 최초 실행 시 SmartScreen 경고가 날 수 있다 → [추가 정보] → [실행].
