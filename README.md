# 화면 주석 QA

비개발자(QA)가 **어떤 사이트에서든** 화면을 클릭해 지적을 남기고, 그것을 셀렉터·좌표·계산된
스타일이 붙은 데이터로 넘기는 도구. UI·기능은 [agentation](https://www.agentation.com) 원본을
그대로 쓰고 **화면 문구만 한글로** 바꾼다.

## 쓰는 사람 입장

1. `화면주석-QA.exe` 더블클릭
2. 주소를 붙여넣고 **[QA 시작]** → 브라우저가 열린다
3. 화면을 클릭해 메모를 남긴다. **페이지를 옮겨도 누를 것이 없다**(툴바가 자동으로 뜬다)
4. 끝나면 **[클립보드 복사]** 또는 **[추출]**

브라우저에 설치되는 것은 **없다** — 북마크·확장·유저스크립트·인증서 전부 없음.
전용 프로필로 열리므로 처음 한 번만 로그인하면 그다음부터 유지된다.

## 왜 이 구조인가 (되돌아가지 않기 위한 기록)

이전에는 북마크릿으로 주입했다. 북마크릿은 구조적으로 두 가지를 못 한다.

| 북마크릿의 한계 | 그래서 붙었던 우회물 |
|---|---|
| 페이지를 옮기면 새 문서 → 사람이 그 화면에서 다시 클릭 | 확장 자동설치(크롬 136+ 차단) → 유저스크립트 → exe 로 북마크 자동등록 |
| 페이지 안에서 실행 → https 화면에서 로컬 수집이 mixed content 로 차단 | 로컬 싱크서버 → 확장 relay → [주석 모으기] 북마크 추가 |

그 우회물이 무거워지자 원본을 버리고 자작 주석기까지 만들었다. **원인은 하나였다 — 주입 경로.**
프로그램이 브라우저를 띄워 CDP 로 주입하면 두 한계가 동시에 사라지고 우회물 전부가 필요 없어진다.

```
[QA 시작] → 브라우저 실행(전용 프로필 + --remote-debugging-port)
          → Page.addScriptToEvaluateOnNewDocument : 모든 새 문서·하위 프레임에 자동 실행
          → Runtime.addBinding('__qaPush') : 주석이 네트워크를 타지 않고 곧장 프로그램으로
```

* 브라우저 설치물 **0** · 페이지당 클릭 **0** · https 정상(mixed content 개념이 성립하지 않음)
* iframe(셸 구조) 자동 — 예전 로더의 1.5초 폴링 해킹이 사라졌다

**여기에 VRT(해상도 순회·캡처 비교)를 넣지 않는다.** 그건 별개 도구가 하는 일이고,
넣으면 한 가지 일을 하는 도구가 또 둘로 갈라진다. 이 도구는 주석만 한다.

## iframe(셸 구조)에서 지킬 것 — 여기서 다 깨졌다

관리자 화면이 `<iframe>` 안에 있는 구조(`/shell` 같은 것)에서 문제가 몰렸다. 손대기 전에 읽을 것.

1. **툴바는 탭마다 하나.** 화면을 지배하는 프레임이 갖는다(부모는 절반 이상 차지하는 같은
   출처 iframe 에 양보, 자식은 그만큼 클 때만 갖는다). 부모·자식이 각각 띄우면 화면상 같은
   자리에 겹치고, 무엇보다 **부모의 전체화면 오버레이가 콘텐츠 클릭을 가로채** iframe 안
   요소를 아예 고를 수 없다.
2. **"떠 있는가" 를 `window` 플래그로 판단하지 말 것.** iframe 은 빈 문서(about:blank)로 먼저
   만들어지고 곧 실제 주소로 바뀌는데 크롬이 **window 를 재사용**한다 → DOM 은 날아가고
   플래그만 남는다. 반드시 DOM(호스트 요소 존재)으로 판단한다.
3. **한 인스턴스는 자기 문서만 담당**(`document !== myDoc` 이면 손을 뗀다). 옛 문서의 타이머가
   살아남아 새 문서에 마크업만 다시 그리면, 스타일은 이미 넣었다고 여겨 다시 넣지 않는다 →
   CSS 없는 툴바가 `position:static` 으로 문서 맨 아래에 깔린다(요소 128개, `<style>` 0개).
4. **`Page.addScriptToEvaluateOnNewDocument` 만 믿지 말 것.** iframe 의 실제 문서에는 걸리지
   않는 경우가 있다. 문서마다 표식(`document.__qaDoc`)을 남기고, 실행 컨텍스트가 생길 때마다
   확인해 빠진 문서에는 프로그램이 직접 넣는다(두 번 들어가도 2번 규칙이 막아 준다).
5. **`Runtime.evaluate` 는 contextId 를 줘야 그 프레임에 들어간다.** 안 주면 최상위 프레임뿐이다.
6. **자가확인은 프레임 전체를, 그리고 "실제로 고정 배치돼 보이는가" 까지** 본다. 호스트 요소
   존재만 보면 CSS 없이 깔린 상태를 "주입됨" 으로 오보고한다(실제로 그랬다).
7. **진단은 숫자로.** 래퍼가 `document.__qaDoc`/`window.__qaInjected`/`window.__qaReady` 를
   남긴다. "툴바가 안 뜬다" 를 추측하지 말고 이 값을 읽어 *주입이 안 온 것*과 *마운트 판단
   문제*를 가른다.

## 모달 위로 올라가기 — z-index 경쟁을 하지 않는다

"모달이 열리면 요소를 고를 수 없다" 를 고친 기록. **z-index 를 올리는 방향으로 되돌아가지 않는다.**

우리 UI 의 최대 z-index 는 100020 이고 페이지는 `2147483647` 을 쓸 수 있다. 사이트별로 숫자를
맞추는 길은 "어떤 사이트에서나" 와 양립하지 않는다. 그래서 **층을 떠나 top layer 로 올라간다** —
top layer 는 정의상 모든 z-index 보다 위여서 경쟁이 성립하지 않는다.

CDP 로 진짜 마우스 클릭을 보내 카운터로 확인한 결과(크롬 151):

| 우리 UI | 방해물 | 클릭이 우리에게 오나 |
|---|---|---|
| 보통 요소(z=100020) | 페이지 오버레이 `z-index:2147483647` | **안 온다** |
| `popover`(top layer) | 같은 오버레이 | **온다** |
| `popover`(top layer) | `dialog.showModal()` | **안 온다** — top layer 안에서도 모달이 최상위고 나머지는 `inert` (여는 순서와 무관) |
| 모달 dialog **안으로 옮긴 UI** | `dialog.showModal()` | **온다** — 클릭·React 이벤트 위임·`position:fixed` 좌표 모두 정상 |

그래서 `src/inject.jsx` 는 이렇게 한다.

1. UI 를 담는 투명한 틀(`#__qa_top_layer`)을 만들어 `popover=manual` 로 **top layer 에 올린다.**
   agentation 이 `document.body` 로 포털한 래퍼를 그 틀 안으로 모은다.
2. **native 모달이 열리면 틀을 그 `<dialog>` 안으로 옮긴다**(`inert` 를 면제받는 유일한 자리).
   닫히면 `body` 로 돌려놓는다. 감지는 `open` 속성 MutationObserver + 클릭 훅 + 주기 검사 —
   **모달이 열린 뒤 0.2초 안에** 올라간다(실측).
3. ★`popover` 승격이 실패하면 **속성을 반드시 떼야 한다.** 속성이 붙은 채 `showPopover()` 가
   안 되면 UA 스타일이 `display:none` 으로 만들어 **툴바가 통째로 사라진다** — 이 도구에서 가장
   나쁜 결과다. 그래서 성공을 `:popover-open` 으로 확인하고, 아니면 되돌린다.
4. **페이지의 모달은 건드리지 않는다.** `showModal` 을 `show` 로 바꿔치기하는 방법도 통하지만
   (실측), 백드롭·포커스 트랩이 사라져 QA 가 보는 화면이 실제와 달라진다. 마지막 수단으로도 쓰지 않는다.

`Esc` 도 같이 고쳤다. 사용법이 안내하는 "Esc 로 모드 끄기" 가 **지적하려던 모달을 함께 닫아
버렸다**(대상 CMS 는 Esc 로 최상위 모달을 닫는다). 주석 모드가 켜져 있고 모달이 열려 있으면
capture 단계에서 Esc 를 페이지로 넘기지 않는다. 모달 판정은 **표준 신호**(`dialog[open]` ·
`aria-modal` · `role=dialog`)로만 한다 — 그 표시가 없는 모달은 가려낼 수 없고, 그 한계를
사용법에 적어 두었다(모드 끄기는 툴바 `[나가기]`).

진단은 숫자로: `window.__qaTop()` 이 틀의 위치·popover 상태·모달 여부·모드 여부·호출 통계를 준다.

## 기기마다 다른 것을 전제로 만든 부분

이 PC 에 다 깔려 있어도 다른 PC 에는 없거나 다르다. 그래서:

| 축 | 어떻게 다루나 |
|---|---|
| 브라우저 | 표준경로 → App Paths 레지스트리 → PATH 순으로 크롬·엣지를 찾는다. 못 찾으면 조치 문장을 띄운다(윈도우 10/11 이면 엣지는 기본 탑재) |
| 파이썬·node·esbuild | **배포 PC 에 불필요.** exe 안에는 이미 만들어진 산출물만 들어간다(`build_exe.py` 가 빌드 전에 검사) |
| 화면 해상도 | **화면 하나의 정체성 = (주소, 해상도).** URL 로만 묶으면 1920 데스크톱과 1366 노트북 결과가 합쳐지고 해상도가 덮어써져 "어디서 깨졌는지"가 사라진다. 창 크기를 바꾸면 새 화면으로 센다 |
| 화면 배율(DPI) | 창 생성 전에 DPI 인식을 켠다. 안 켜면 125·150·200% 화면에서 창 전체가 흐릿하게 확대된다 |
| 창 크기 | 실제 화면 크기에 맞춰 접어 넣고 가운데 정렬(800×600 까지 확인) |
| 폰트 | 맑은 고딕 → Malgun Gothic → Segoe UI → Noto Sans KR 순으로 설치된 것을 고른다 |
| 저장 위치 | `%LOCALAPPDATA%\qa-annotator` (exe 옆에 쓰지 않는다 — USB·읽기전용 공유에서도 동작) |
| 포트 | 매번 빈 포트를 받는다(고정 포트 없음) |

## 사용자용 문서

`docs/사용법.html` — exe 에 동봉되고, 창 오른쪽 위 **[사용법]** 버튼이 이를 `%LOCALAPPDATA%` 로
꺼내 기본 브라우저로 연다.

구성(9절): 흐름 그림 → 시작하기 → **화면에 주석 남기기**(hover·memo 그림) →
**팝업(모달)** → 관리자 화면(툴바 위치 표) → **프로그램 창**(목록 그림) →
**보강 창**(기대·우선순위·연결 그림) → 결과에 담기는 것 → 막힐 때 → 알아두면 좋은 것.

**읽는 사람 기준으로 줄였다.** 툴바 아이콘 8개 표 · 설정 항목 표 · 지우기 대조표 ·
영역별 방법 6가지는 **뺐다** — 실사용에서 쓰이지 않고 문서만 길어졌다. 대신
"이렇게 하면 → 이렇게 됩니다" 표 4줄로 줄이고 **그림으로 대체**했다.

**고치는 방법**: `docs/사용법.src.html` 을 고치고 `python docs/make_help.py` → `docs/사용법.html`.
직접 `사용법.html` 을 고치면 다음 생성에서 덮어써진다.

* 그림은 **실제 화면을 캡처한 것**이고 `docs/icons/*.png` 에 있다. `{{img:파일명}}` 자리를
  make_help.py 가 **data URI 로 박는다** — [사용법] 은 HTML 한 개만 꺼내 열기 때문에 바깥
  파일을 참조하면 그림이 깨진다(한 파일로 자립해야 한다).
* 전체 흐름은 **인라인 SVG** 로 그렸다(그림 파일이 아니다) — 문구를 고칠 때 캡처를 다시
  뜨지 않아도 되고 무게도 0 이다.
* 그림을 다시 뽑을 때: 스크래치패드의 `capture_browser.py`(브라우저 쪽 `hover`·`memo` —
  CDP `Page.captureScreenshot`) · PowerShell 창 캡처(프로그램 쪽 `app-list`·`app-detail` —
  `EnumWindows` 로 창을 찾아 `CopyFromScreen`. 보강 창은 **주 창이 아니라서**
  `MainWindowTitle` 로는 안 찾아진다).
* ★**자르지 말 것.** 메모 팝업은 화면 오른쪽까지 걸쳐 있어 잘라내면 [추가] 버튼이 날아간다
  (실제로 그랬다). 전체 화면을 **배율 1.2** 로 뜬다 — 2배는 문서가 368KB 까지 커졌다.
* 쓰지 않게 된 `toolbar.png`·`icon0*.png` 는 남겨 둔다(다시 아이콘 표가 필요해질 때를 위해).
  make_help.py 는 **문서가 참조하는 그림만** 박는다.

## 그 밖에 지킬 것

* ★**클립보드는 반드시 네이티브(Windows API)로 쓴다.** `tkinter` 의 `clipboard_append` 는 Tk 가
  클립보드를 소유하는 방식이라 **프로그램을 닫으면 내용이 사라진다**(실측). QA 의 실제 동작은
  "복사 → 프로그램 닫기 → 붙여넣기" 이므로 그대로 두면 매번 잃는다. `set_clipboard()` 를 쓰고
  실패할 때만 tk 로 폴백한다(그 경우엔 "닫지 마세요" 를 로그로 알린다).

* **프로그램은 한 번에 하나만 돈다**(Windows named mutex). 사람들은 아이콘을 여러 번 누른다 —
  여러 개가 뜨면 각자 브라우저에 주입을 등록하고 같은 결과 파일에 쓴다(실제로 4개가 떠 있었다).
* **프로그램을 다시 켰는데 브라우저가 아직 떠 있는 경우**가 흔하다. 같은 프로필로 크롬을 또
  띄우면 크롬은 기존 창에 넘기고 스스로 종료하므로 새 포트가 열리지 않는다. 그래서 우리가
  포트를 `session.json` 에 적어 두고 **기존 창에 다시 붙는다**(크롬의 `DevToolsActivePort` 는
  넘어간 프로세스가 지워 버려 2순위).
* **기동 중을 "닫힘" 으로 판단하지 말 것.** `alive()` 가 CDP 기준이므로, 아직 붙기 전에는
  살아 있는 것으로 봐야 한다. 안 그러면 창의 주기 갱신이 기동을 취소한다(실측).
* **테스트는 스크래치패드 전용 폴더로만.** 개발 중 `%LOCALAPPDATA%\qa-annotator\out` 에 테스트
  주석을 남겨 사용자 결과에 섞인 일이 있었다.

## 결과

`%LOCALAPPDATA%\qa-annotator\out\`

* `latest.md` — 화면별로 묶인 전달용 문서. 화면마다 주소·해상도·DPR·시각 + 주석 + 그 화면의
  콘솔 에러·실패한 요청. 맨 앞에 **총평**(추출·복사 때 사람이 적는 마지막 코멘트),
  주석마다 **시각**·**보충**·**관련**(다른 화면 주석과의 연결)
* `annotations.jsonl` — 이벤트 원본. 프로그램을 다시 켜면 이걸 재생해 목록을 복원한다
* `archive/` — [비우기]·[추출] 때 옮겨 둔 이전 기록

## 보충·연결·총평은 주석 '안' 에 넣지 않는다

`store.apply()` 는 브라우저가 보낸 주석 dict 를 **id 로 통째 덮어쓴다**. 주석 객체 안에 우리
필드를 넣으면 사용자가 브라우저에서 메모를 한 번 고치는 순간 날아간다. 그래서 프로그램이 쓰는
것은 별도 맵(`store.meta`) + 별도 이벤트(`{'t':'meta'}` · `{'t':'closing'}`)로 둔다.

* 연결은 **주석 id 로 저장하고 화면·주석 번호는 렌더 시점에 해석한다.** 번호를 저장하면 화면
  순서가 바뀌는 순간(되돌아온 화면·해상도 변경) 참조가 어긋난다.
* 목록(`tree_rows`)과 결과(`render`)는 **같은 `_render_pages()` 를 쓴다.** 따로 걸러 세면
  목록의 `[화면 2]` 와 문서의 `[화면 2]` 가 달라져 연결을 읽을 수 없다.
* 지운 주석의 메타는 함께 버리지만, **그것을 가리키던 연결은 남겨 `(삭제된 주석)` 으로 보여
  준다** — 조용히 사라지지 않게.
* 모르는 `t` 는 무시한다 — 옛 `jsonl` 과 앞으로의 확장 양쪽을 위해.

## 실사용자 요구를 반영한 부분 (되돌리지 않기 위한 기록)

첫 실사용 라운드에서 나온 요구를 어디에 어떻게 넣었는지. **왜 그렇게 했는지가 중요한 것들만.**

| 요구 | 구현 | 왜 그 방법인가 |
|---|---|---|
| 팝업 뒤로 툴바가 넘어가 안 눌린다 | top layer 승격(위 절) | z-index 경쟁은 구조적으로 진다 |
| 한 번 클릭에 메모창이 뜬다 → 더블클릭으로 | `src/inject.jsx` 캡처단계 click | **첫 클릭은 `stopImmediatePropagation`**(agentation 까지 차단), 두 번째는 `stopPropagation`(agentation 은 받고 페이지는 못 받음). 리스너 순서가 이 구현의 전부다 — 우리가 `start()` 에서 먼저 등록되므로 성립한다 |
| 썸네일 클릭이 미리보기를 띄운다 | 같은 리스너 | agentation 의 `blockInteractions` 는 `button·a·input·select·textarea·[role=button]·[onclick]` 만 막는다. 썸네일은 `img`/`div` + 위임 핸들러라 새어 나갔다 |
| 이동할 때 껐다 켜는 게 불편 | `Esc` 로 토글 | 켜기는 접힌 둥근 버튼을 **좌표로 찾아** 누른다(문구로 찾으면 한글화 표가 바뀔 때 조용히 깨진다). ★모달이 열려 있으면 켜지 않는다 — 그 Esc 는 모달을 닫으려는 것이다 |
| 입력 영역이 좁다 | 팝업의 textarea 를 2배 | 숫자를 박지 않고 **그때 크기의 2배**로 만든다(기기·글꼴마다 다르다). ★노드에 `data-qa-grown` 표식을 남긴다 — 팝업이 닫혔다 같은 노드로 다시 열릴 때 또 2배가 되어 폭주했다(실측 280×52 → 1169×456) |
| 팝업 버튼이 화면 밖으로 밀린다 | 뷰포트 안으로 당김 | 커진 팝업이 잘리면 확정 버튼을 못 누른다 |
| 실수로 지웠을 때 되돌리기 | `store.undo()` | **기록을 고치지 않는다.** `{'t':'skip','index':N}` 를 덧붙이고 전체를 다시 재생한다 — 원본 줄이 증거다 |
| 추출한 데이터를 다시 불러오기 | `store.load_archive()` | archive 의 줄을 **현재 기록에 합친다.** 따로 보관하면 진실이 두 곳이 되고 다음 추출에서 무엇이 들어갔는지 셀 수 없다 |
| 순서를 바꾸고 싶다 | 목록에서 `Ctrl+↑/↓` | 화면 그룹은 그대로 두고 **화면 안 순서만** 사람이 정한다(`{'t':'order'}`). 화면 정체성 `(주소, 해상도)` 를 건드리지 않는다 |
| 우선도로 정렬 | 목차를 우선순위순 | 본문은 화면 그룹을 유지한다. ★**미지정을 '낮음' 보다 앞**에 둔다 — '낮음' 은 나중에 해도 된다고 사람이 판단한 것이고 미지정은 아직 판단이 안 된 것이다 |
| 목록의 URL 로 이동 | 목록 우클릭 → 이 화면으로 이동 | `navigate()` 가 이미 있다 |
| 레이아웃 변경 개수를 알고 싶다 | **브라우저 화면**의 툴바 위 표시 + 프로그램 배지 | 요구가 "주석 모드에서도 알 수 있으면" 이었다 - 화면을 보는 중에 알아야 하므로 브라우저 쪽에 둔다. **누를 수 없는 표시**(`pointer-events:none`)라 툴바를 늘리지 않는다. top layer 틀 안에 있어 모달 위에서도 보인다 |
| 목록의 URL 로 이동 | **주소 열 클릭** + 우클릭 메뉴 | 요구가 "url 을 클릭하면" 이었다. 다른 열을 눌러도 이동하면 오작동이 되므로 `identify_column` 으로 주소 열만 받는다 |
| 순서를 바꾸고 싶다 (화면끼리) | 화면 줄에서 `Ctrl+↑/↓` | `{'t':'porder','keys':[…]}`. **화면 정체성 `(주소, 해상도)` 는 건드리지 않는다** — 순서만 바꾼다. 화면 번호는 렌더 시점에 다시 붙고, 연결(`- 관련:`)도 그때 해석하므로 참조가 어긋나지 않는다 |

### 와이어프레임 불투명도 · 툴바 위치 (2차)

| 요구 | 구현 | 왜 그 방법인가 |
|---|---|---|
| 와이어프레임이 불투명해 아래 화면이 안 보인다 | 기본값 1 → **0.5** | agentation 이 `--canvas-opacity` 로 이미 조절점을 만들어 뒀고 **사용자 슬라이더(0~1)도 있다.** 그래서 CSS 로 덮지 않았다 — 덮으면 슬라이더가 죽는다. `ko.strings.json` 의 **`patches` 절**(번역이 아닌 동작 치환, 사유 필수)에서 `useState6(1)` → `useState6(0.5)` 로 바꾼다. `build_ko.py` 가 rules 와 **따로 세고** 게이트에 함께 넣는다 |
| 와이어프레임·주석에 좌측 메뉴·상단바가 빠진다 | **툴바를 최상위 화면에 고정** 하는 스위치 | ★이중 마운트로 돌아가지 않는다(iframe 규칙 1의 사고 경로). **"lnb·gnb 포함" 과 "iframe 내부 선택" 은 동시에 성립하지 않는다** — 문서가 다르면 히트테스트가 안 된다. 그래서 사람이 고른다. 프로그램 창 체크박스 → `window.__qaForceTop` → `shouldMount()` 가 최상위만 허용 |

전환은 `launcher.set_force_top()` 이 지금 떠 있는 문서에도 바로 적용한다.
★`__qaClear` 를 쓰지 않는다 — 그것은 저장된 주석까지 지운다. 그래서 **`__qaRemount`** 를 따로 뒀다.

`Esc` 위임(셸 구조): 툴바가 없는 문서가 Esc 를 받으면 **자식·부모 양방향**으로 넘긴다.
사람이 iframe 안을 한 번 클릭하면 포커스가 그 문서로 옮겨가므로 아래로만 넘기면 안 먹는다(실측).
켤 때는 **320ms 뒤 한 번만 재시도**한다 — 툴바 등장 애니메이션 중에는 클릭이 무시된다(실측).

**아직 안 한 것**: 지라 댓글 자동 등록(외부 전송이라 별건 — 사용자 지시로 제외).

## 스크린샷을 붙이지 않는다 — 그래서 텍스트가 그림의 일을 해야 한다

★**주석마다 스크린샷을 붙이는 기능을 넣지 않는다.** 스크린샷 첨부를 없애려고 만든 도구다
(셀렉터·좌표·계산된 스타일로 넘긴다). 붙이면 이 도구의 존재 이유가 사라진다 — **회귀다.**

그래서 "그림을 보내 달라" 는 말이 나오는 쪽을 텍스트로 막는다. 실제 QA 회신에서 나온 요구를
도구가 스스로 처리하게 옮긴 것:

| QA 가 되묻던 것 | 도구가 하는 일 |
|---|---|
| "다크에서 캡처한 색값인지 몰라 색 지적의 기준이 어긋난다" | 화면마다 **`- 색 기준:`** — 배경색·`color-scheme`·브라우저 선호를 적는다. 테마를 강제하지는 않는다(할 수 없다) |
| "정렬이 안 맞는다 를 글로는 못 읽는다" | 묶어 잡은 주석에 **`- 정렬:` `- 크기:` `- 세로 간격:`** — 좌/우 x, 폭·높이, 인접 간격을 숫자와 최대 차이로 낸다(`elementBoundingBoxes` 는 지금까지 버려지고 있었다) |
| "안쪽으로 옮겨 달라 의 기준이 없다" | **`- 배치:`** — `display`·`padding`·`gap`·정렬 속성만 뽑아 앞에 세운다. `- 스타일:` 은 300자에서 자르는데 정작 이 값들이 뒤에 있어 잘려 나갔다 |
| "지금 어떻고 어떻게 되어야 하나" | 주석 메모가 **현재**, 프로그램에서 적는 **`- 기대:`** 가 기대. **`- 우선순위:`** 도 함께 |
| "이슈 댓글이 '첨부하였습니다' 한 줄이라 검색에 안 걸린다" | 문서 맨 앞 **`## 항목 N건`** — 한 줄씩이라 댓글에 그대로 붙인다 |

## 개발 (빌드 PC 에서만)

```
python build_ko.py       # 번역 적용 + 게이트 3종. 실패하면 종료코드 1
python build_inject.py   # esbuild 번들 → DOM 준비 후 실행하도록 감쌈
python build_exe.py      # release/화면주석-QA.exe (+ 바탕화면 복사)
```

`build_ko.py` 의 게이트는 숫자로 증명한다 — **못 찾음 0 · 개수 불일치 0 · 잔존 영문 UI 0**.
"꼼꼼히 봤다"는 지킨 척이 가능하지만 "잔존 0"은 파일을 조작하지 않으면 거짓말할 수 없다.
번역표는 `ko.strings.json` 하나다. 새 문구가 보이면 거기에 넣고, UI 가 아니면 `allow` 에
**사유와 함께** 등록한다(조용한 면제 금지 — 실제로 `Webhooks` 를 그렇게 놓쳤고 눈 대조에서 잡았다).

* 요소 유형명(`Button`·`Card` …)은 영문으로 남긴다 — 주석 결과의 `element` 필드에 박히고
  개발자·AI 가 그 이름으로 코드를 찾는다(`COMPONENT_MAP[type].label` 이 그대로 쓰인다).
* 원본 `node_modules/agentation/dist/index.mjs` 는 **읽기만** 한다. 치환은 사본에만.

## 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 프로그램 창(tkinter). 주소 입력 · 목록 · 복사/추출/비우기 |
| `launcher.py` | 브라우저 탐색·실행, 타깃 자동 부착, 주입, 콘솔·네트워크 수집 |
| `cdp.py` | CDP 클라이언트. 표준 라이브러리만(RFC6455 최소 구현) — 다른 PC 재현성을 위해 외부 의존 0 |
| `store.py` | (주소, 해상도) 단위 누적 · `latest.md`/`jsonl` 출력 · 재시작 복원 · 프로그램 소유 메타(보충·연결·총평) |
| `src/inject.jsx` | 주입 스크립트. agentation 마운트 + 화면 정보 통지 |
| `ko.strings.json` | 번역표(원문·한글·사유) + allow 목록 |

## 라이선스

`agentation` 은 **PolyForm Shield 1.0.0** 이다. 사내 QA 용도로 쓰고, 경쟁 제품으로 쓰지 않으며,
재배포 시 라이선스를 동봉한다. 원본 패키지는 수정하지 않고 문구만 바꾼 사본을 만들어 쓴다.

서명 없는 exe 라 최초 실행 시 SmartScreen 경고가 날 수 있다 → [추가 정보] → [실행].
